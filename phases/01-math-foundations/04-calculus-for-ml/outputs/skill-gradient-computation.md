# حساب التدرج لـ ML
مرجع عملي لحساب تدرجات وظائف الخسارة ووظائف التنشيط وعمليات الطبقة المستخدمة في الشبكات العصبية.
## قائمة مراجعة القرار
1. هل تتكون الدالة من عناصر أولية بسيطة (الطاقة، الخبرة، السجل، حساب المثلثات)؟ استخدام المشتقات التحليلية وقاعدة السلسلة.
2. هل الوظيفة مخصصة أم عملية الصندوق الأسود؟ استخدم التمايز العددي: `(f(x+h) - f(x-h)) / (2h)` مع h = 1e-7.
3. هل تم إنشاء الدالة من عمليات الموتر في PyTorch/JAX؟ دع Autograd يتولى الأمر. التحقق من خلال التحقق الرقمي.
4. هل تحتاج إلى تدرج الخسارة العددية w.r.t. مصفوفة الأوزان؟ قم بتطبيق قاعدة السلسلة من خلال الرسم البياني الحسابي، بمعدل node واحد في كل مرة.
5. هل هناك عملية غير قابلة للتفاضل (argmax، التقريب، أخذ العينات)؟ استخدم أداة تقدير مباشرة أو خدعة إعادة المعلمة.

| عددية (اختلافات محدودة) | تصحيح الأخطاء، فحص التدرج، وظائف الصندوق الأسود | 2n يمرر للأمام لمعلمات n |

## مرجع سريع: المشتقات المشتركة
| وظيفة | و(خ) | و '(خ) | ML السياق |
|---|---|---|---|
| MSE الخسارة | (1/ن) مجموع(y_hat - y)^2 | (2/ن)(y_hat - y) | الانحدار |
| إنتروبيا متقاطعة (ثنائية) | -(y log(p) + (1-y) log(1-p)) | ص - ص (بعد السيني) | التصنيف الثنائي |
| إنتروبيا متقاطعة (متعددة) | -سجل (p_true_class) | ص - one_hot(y) (بعد softmax) | تصنيف متعدد الطبقات |
| السيني | 1 / (1 + ه^(-x)) | سيجما(x) * (1 - سيجما(x)) | بوابات الإخراج، الإخراج الثنائي |
| تنه | (e^x - e^(-x)) / (e^x + e^(-x)) | 1 - تانه(x)^2 | التنشيطات المخفية (القديمة) |
| ريلو | الحد الأقصى (0، س) | 1 إذا س > 0، 0 إذا س < 0 | التنشيط المخفي الافتراضي |
| متسرب ReLU | الحد الأقصى (0.01x، x) | 1 إذا كان x > 0، 0.01 إذا كان x < 0 | تجنب الخلايا العصبية الميتة |
| __المصطلح_2__ | س * فاي(س) | فاي(x) + x * فاي(x) | المحولات |
| سوفت ماكس_i | e^(x_i) / مجموع(e^(x_j)) | s_i(1 - s_i) لـ i=j, -s_i*s_j لـ i!=j | طبقة الإخراج (جاكوبيان) |
| سجل سوفت ماكس | x_i - سجل(مجموع(e^(x_j))) | 1 - softmax(x_i) للمدخل i | مستقر عدديًا CE |
| الطبقة الخطية | ص = وس + ب | dL/dW = dL/dy * x^T, dL/db = dL/dy | كل طبقة |
| L2 التسوية | لامدا * مجموع (ث ^ 2) | 2 * لامدا * ث | تسوس الوزن |
| L1 التسوية | لامدا * مجموع (\|ث\|) | لامدا * علامة (ث) | سبارسيتي |
##أخطاء شائعة
- نسيان عامل 1/n في متوسط ​​خسائر الدفعة (MSE، الإنتروبيا المتقاطعة). يتم تحجيم التدرج حسب حجم الدفعة.
- حساب تدرج softmax كمتجه عندما يكون في الواقع مصفوفة جاكوبي. بالنسبة للإنتروبيا المتقاطعة + softmax مجتمعة، يتم تبسيط التدرج إلى (p - y)، مما يتجنب اليعقوبي الكامل.
- تطبيق قاعدة السلسلة بالترتيب الخاطئ. العمل للخلف من الخسارة: dL/dW = dL/dy * dy/dW.
- استخدام h كبير جدًا (h = 0.1) أو صغير جدًا (h = 1e-15) للمشتقات الرقمية. التزم بـ h = 1e-7 لـ float64.
- نسيان أن ReLU له تدرج غير محدد عند x = 0 بالضبط. ومن الناحية العملية، اضبطه على 0 أو 0.5.
## وصفة فحص التدرج
```
For each parameter w:
  numeric_grad = (loss(w + h) - loss(w - h)) / (2h)
  auto_grad = backward pass value
  relative_error = |numeric - auto| / max(|numeric|, |auto|, 1e-8)
  assert relative_error < 1e-5
```

الخطأ النسبي فوق 1e-3 يعني وجود خطأ ما. بين 1e-5 و1e-3، تحقق.
