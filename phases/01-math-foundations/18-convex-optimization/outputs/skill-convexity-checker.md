# مدقق التحدب
كيفية التحقق مما إذا كانت مشكلة التحسين محدبة، وماذا تفعل بالإجابة.
## قائمة مراجعة القرار
1. هل الدالة الموضوعية محدبة؟ (تحقق من شبه التحديد الإيجابي لـ Hessian أو استخدم قواعد التركيب.)
2. هل جميع قيود عدم المساواة في النموذج g_i(x) <= 0 حيث يكون كل g_i محدبًا؟
3. هل جميع قيود المساواة مترابطة (خطية)؟
4. إذا كانت الإجابة على الأسئلة الثلاثة نعم، فإن المشكلة محدبة. استخدام حلالا محدبا مع ضمانات التقارب.
5. إذا لم يكن هناك أي شيء، فالمشكلة غير محدبة. استخدم SGD/Adam واقبل الأمثلية المحلية.
## كيفية اختبار تحدب الدالة
| اختبار | ينطبق على | الطريقة |
|---|---|---|
| المشتق الثاني >= 0 | الدوال العددية f(x) | حساب f''(x). إذا كانت f''(x) >= 0 لجميع x، فهي محدبة. |
| هسه هو PSD | دوال متعددة المتغيرات f(x) | حساب H(x). إذا كانت جميع القيم الذاتية >= 0 في كل مكان، فهي محدبة. |
| اختبار التعريف | أي وظيفة | تحقق من f(tx + (1-t)y) <= t*f(x) + (1-t)*f(y) لعينات x، y، t. |
| قواعد التكوين | الدوال المركبة | انظر جدول التكوين أدناه. |
| تقييد على خط | متعدد المتغيرات و | f محدب إذا كان g(t) = f(x + tv) محدبًا في t لكل x, v. |
## قواعد التكوين (الحفاظ على التحدب)
| عملية | النتيجة |
|---|---|
| f + g (كلاهما محدب) | محدب |
| ج * و (ج > 0، و محدب) | محدب |
| الحد الأقصى (f، g) (كلاهما محدب) | محدب |
| f(Ax + b) حيث f محدب | محدب |
| g(f(x)) حيث g محدب غير متناقص و f محدب | محدب |
| g(f(x)) حيث g محدب غير متزايد وf مقعر | محدب |
| مجموع الدوال المحدبة | محدب |
| القمة النقطية للدوال المحدبة | محدب |
## أهداف ML المشتركة: محدبة أم لا؟
| الهدف | محدب؟ | السبب |
|---|---|---|
| MSE: (1/n) مجموع(y - Xw)^2 | نعم | التربيعية في w، هسي = (2/n) X^T X هو PSD |
| الخسارة اللوجستية: sum(log(1 + exp(-y_i * w^T x_i))) | نعم | مجموع الدوال المحدبة (عائلة log-sum-exp) |
| خسارة المفصلة: sum(max(0, 1 - y_i * w^T x_i)) | نعم | الحد الأقصى للوظائف المحدبة (الخطية) |
| L2 التنظيم: لامدا * \|\|w\|\|^2 | نعم | تربيعي، هسي = 2*لامدا*I |
| L1 التنظيم: لامدا * \|\|w\|\|_1 | نعم | مجموع القيم المطلقة (محدبة ولكن غير قابلة للتفاضل) |
| انحدار ريدج: MSE + L2 | نعم | مجموع دالتين محدبتين |
| LASSO: MSE + L1 | نعم | مجموع دالتين محدبتين |
| شبكة مرنة: MSE + L1 + L2 | نعم | مجموع الدوال المحدبة |
| SVM (أولي): المفصلي + L2 | نعم | مجموع الدوال المحدبة |
| الانتروبيا المتقاطعة مع softmax | نعم (في logits) | Log-sum-exp محدب |
| الشبكة العصبية (أي خسارة) | لا | تؤدي التنشيطات غير الخطية إلى إنشاء تركيبة غير محدبة |
| ك-تعني الهدف | لا | خطوة الاحالة المنفصلة |
| تحليل المصفوفة: \|\|X - UV^T\|\|^2 | لا | ثنائي في U و V |
| GAN الخسارة | لا | Minimax، غير محدب في المولد |
| الخسارة التباينية (InfoNCE) | لا | سجل نسبة الأسس مع العينات السلبية |

##أخطاء شائعة
- بافتراض أن المشكلة محدبة لأن دالة الخسارة محدبة. يجب أن تكون الخسارة محدبة في المعلمات التي تقوم بتحسينها. الإنتروبيا المتقاطعة محدبة في logits، لكن تعيين الشبكة العصبية الكامل من المدخلات إلى logits غير محدب.
- استخدام طريقة نيوتن في المسائل غير المحدبة. قد يكون لقيم هيسيان قيم ذاتية سلبية، مما يتسبب في تحرك نيوتن نحو نقاط السرج أو الحد الأقصى بدلاً من الحد الأدنى.
- متناسين أن L1 التنظيم make هو الهدف غير القابل للتفاضل عند الصفر. النسب التدرج القياسي لا يعمل بشكل جيد. استخدم النسب التدرج القريب أو أساليب التدرج الفرعي.
- تربيع رقم الشرط بتكوين A^T A. إذا كنت تريد حل مسألة المربعات الصغرى وكان A شرطيًا سيئًا، فاستخدم QR أو SVD بدلاً من المعادلات العادية.
- الإعلان عن مشكلة غير محدبة دون التحقق منها. العديد من مشكلات ML (النماذج الخطية، وSVMs، والانحدار اللوجستي) تكون محدبة وتستفيد من حلول أقوى.
## اختبار سريع: هل مشكلتي محدبة؟
```
1. Write out the objective: minimize f(w) subject to constraints
2. For each term in f(w):
   - Is it quadratic with PSD matrix? -> Convex
   - Is it a norm? -> Convex
   - Is it log-sum-exp? -> Convex
   - Does it involve w nonlinearly (sigmoid(w), w1*w2)? -> Likely non-convex
3. Are all constraints linear or convex inequalities?
4. If ALL terms are convex and constraints are convex/linear -> problem is convex
5. If ANY term is non-convex -> problem is non-convex
```
