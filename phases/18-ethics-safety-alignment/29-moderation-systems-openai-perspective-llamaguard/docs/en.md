# أنظمة الإشراف — OpenAI، المنظور، حارس اللاما
> تعمل أنظمة الإشراف على الإنتاج على تفعيل سياسات السلامة المحددة في الدروس 12-16. OpenAI الإشراف API: `omni-moderation-latest` (2024) المبني على GPT-4o يصنف النص + الصور في مكالمة واحدة؛ أفضل بنسبة 42% في مجموعة الاختبارات متعددة اللغات مقارنة بالإصدار السابق؛ يعرض مخطط الاستجابة 13 قيمة منطقية للفئة - التحرش، التحرش/التهديد، الكراهية، الكراهية/التهديد، غير المشروع، غير المشروع/العنف، إيذاء النفس، إيذاء النفس/النية، إيذاء النفس/التعليمات، الجنسي، الجنسي/القاصرين، العنف، العنف/الرسومات؛ مجاني لمعظم المطورين. أنماط الطبقات: الإشراف على الإدخال (الإنشاء المسبق)، والإشراف على الإخراج (الجيل اللاحق)، والإشراف المخصص (قواعد المجال). المكالمات المتوازية غير المتزامنة تخفي زمن الاستجابة؛ استجابات العناصر النائبة على العلم. Llama Guard 3/4 (الدرس 16): 14 مخاطر MLCommons، إساءة استخدام مترجم الكود، 8 لغات (الإصدار 3)، صور متعددة (الإصدار 4). المنظور API (Google Jigsaw): سجل السمية الذي يسبق موجة LLM كمشرف؛ في المقام الأول سمية أحادية البعد مع متغيرات شديدة السمية/الإهانة/الألفاظ النابية؛ خط الأساس لأبحاث إدارة المحتوى. عمليات الإيقاف: تم إهمال وسيط محتوى Azure في فبراير 2024، وتم إيقافه في فبراير 2027، وتم استبداله بـ Azure AI أمان المحتوى.
**النوع:** بناء
**اللغات:** Python (stdlib، أداة اعتدال ثلاثية الطبقات)
**المتطلبات الأساسية:** المرحلة 18 · 16 (حارس اللاما / جاراك / بيريت)
**الوقت:** ~60 دقيقة
## أهداف التعلم
- قم بوصف تصنيف فئة OpenAI للإشراف API وكيف يختلف عن مجموعة MLCommons في Llama Guard 3.
- وصف نمط طبقة الاعتدال الثلاثة (الإدخال، الإخراج، المخصص) وتسمية وضع فشل واحد لكل منها.
- وصف موقف API للمنظور باعتباره خط الأساس لعصر ما قبل LLM ولماذا يظل مستخدمًا في البحث.
- تحديد الجدول الزمني لإيقاف Azure.
## المشكلة
تصف الدروس 12-16 الهجمات وأدوات الدفاع. يغطي الدرس 29 أنظمة الإشراف المنشورة التي تعمل على تفعيل الدفاعات على السطح حيث يلمس المستخدمون المنتج. النمط ثلاثي الطبقات هو التكوين الافتراضي لعام 2026.
##المفهوم
### OpenAI الإشراف API
`omni-moderation-latest` (2024). مبني على GPT-4o. يصنف النص + الصور في مكالمة واحدة. مجاني لمعظم المطورين.
الفئات (13 قيمة منطقية في مخطط الاستجابة):
- التحرش، التحرش/التهديد
- الكراهية والكراهية / التهديد
- إيذاء النفس، إيذاء النفس/النية، إيذاء النفس/التعليمات
- الجنسية والجنسية / القصر
- العنف والعنف/الرسم
- غير مشروع، غير مشروع/عنيف
ينطبق دعم الوسائط المتعددة على `violence` و`self-harm` و`sexual` ولكن ليس `sexual/minors`؛ والباقي نص فقط.
بالنسبة إلى مجموعة التعليمات البرمجية في `code/main.py`، قمنا بدمج الفئات الفرعية `/threatening` و`/intent` و`/instructions` و`/graphic` في الفئات الرئيسية ذات المستوى الأعلى من أجل البساطة التربوية. يجب أن يستخدم رمز الإنتاج المخطط الكامل المكون من 13 فئة.
أفضل بنسبة 42% في مجموعة الاختبارات متعددة اللغات مقارنة بنقطة النهاية للإشراف من الجيل السابق. عشرات لكل فئة. تحدد التطبيقات عتبات.
### حارس اللاما 3/4
تمت تغطيتها في الدرس 16. 14 فئة خطر MLCommons (منظمة بشكل مختلف عن OpenAI منطقية مخطط الاستجابة البالغ عددها 13). يدعم 8 لغات (الإصدار 3). Llama Guard 4 (أبريل 2025) هي في الأصل متعددة الوسائط، 12B.
تتداخل تصنيفات OpenAI وLlama Guard ولكنها تتباعد. OpenAI يحتوي على "غير مشروع" كفئة واسعة؛ يحتوي Llama Guard على "جرائم عنيفة" و"جرائم غير عنيفة" بشكل منفصل. يتم اختيار عمليات النشر بناءً على توافقها مع تصنيف السياسة.
### المنظور API (Google Jigsaw)
نظام تسجيل السمية يسبق موجة LLM كمشرف (قبل عام 2020). الفئات: السمية، السمية الشديدة، INSULT، الألفاظ النابية، THREAT، IDENTITY_ATTACK. النتيجة الأولية أحادية البعد (السمية) مع متغيرات البعد الفرعي.
يُستخدم على نطاق واسع كخط أساس لأبحاث الإشراف على المحتوى نظرًا لأن API مستقر وموثق ويحتوي على سنوات من بيانات المعايرة. بالنسبة لحالات الاستخدام الحديثة المجاورة لـ LLM، عادةً ما يكون Llama Guard أو OpenAI الاعتدال أكثر ملائمة.
### النمط ثلاثي الطبقات
1. **الإشراف على الإدخال.** قم بتصنيف مطالبة المستخدم قبل الإنشاء. رفض إذا تم وضع علامة عليها. الكمون: استدعاء مصنف واحد.
2. **الإشراف على الإخراج.** تصنيف مخرجات النموذج قبل التسليم. استبدل بالرفض إذا تم وضع علامة عليه. الكمون: استدعاء مصنف واحد بعد الجيل.
3. **الإشراف المخصص.** القواعد الخاصة بالنطاق (التعبير العادي، والقوائم المسموح بها، وسياسة العمل). يعمل عند الإدخال أو الإخراج.
الطبقات الثلاث متسلسلة حسب التصميم: يجب أن يكتمل الإشراف على الإدخال قبل الإنشاء، ويعمل الإشراف على الإخراج بعد الإنشاء. ينطبق التوازي داخل الطبقة - يؤدي تشغيل مصنفات متعددة (على سبيل المثال، OpenAI الاعتدال + Llama Guard + Perspective) بشكل متزامن على نفس النص إلى إخفاء زمن الاستجابة لكل مصنف. كتحسين اختياري، قد يتم عرض استجابة العنصر النائب ("لحظة واحدة، التحقق...") أثناء اكتمال الإشراف على الإدخال وتأجيل تدفق الرمز المميز 1. سلوك الإبلاغ قابل للتكوين: الرفض والتعقيم والتصعيد إلى المراجعة البشرية.
### أوضاع الفشل
- **الإدخال فقط.** لا يلتقط هلوسة الإخراج (الدرس 12-14 تتجاوز هجمات التشفير مصنفات الإدخال).
- **الإخراج فقط.** يسمح لأي مدخلات بالوصول إلى النموذج؛ يزيد التكلفة؛ سطوح المنطق الداخلي للمهاجم.
- **مخصص فقط.** ليس قويًا عبر الفئات؛ التعابير المنطقية هشة.
الطبقات هي الافتراضية. الحزام والحمالات.

مشرف محتوى Azure: تم إهماله في فبراير 2024، وتم إيقافه في فبراير 2027. تم استبداله بـ Azure AI أمان المحتوى، الذي يستند إلى LLM ويتكامل مع Azure OpenAI. يعد الترحيل مشروعًا على المستوى الميداني للفترة 2024-2027 لعمليات نشر Azure.

## استخدمه
ينشئ `code/main.py` أداة للإشراف من ثلاث طبقات: وسيط الإدخال (الكلمات الرئيسية + نقاط الفئة)، وسيط الإخراج (نفس المصنف في الإخراج)، وسيط مخصص (قواعد المجال). يمكنك تشغيل المدخلات من خلال ومراقبة الطبقة التي تلتقط ما.
## اشحنها
ينتج هذا الدرس `outputs/skill-moderation-stack.md`. نظرًا للنشر، فإنه يوصي بتكوين مكدس الإشراف: أي مصنف عند الإدخال، وأي مصنف عند الإخراج، وما هي القواعد المخصصة، وما الذي يحكم على حالات الحافة.
## تمارين
1. قم بتشغيل `code/main.py`. قم بتشغيل مدخلات حميدة وحدودية وضارة عبر الطبقات الثلاث. قم بالإبلاغ عن الطبقة التي تشتعل لكل منها.
2. قم بتمديد الحزام باستخدام أسلوب تسجيل السمية بنمط المنظور API على فئة معينة. قارن سلوك العتبة بدرجة الفئة.
3. اقرأ مستندات OpenAI الإشراف API وقائمة فئات Llama Guard 3. قم بتعيين كل فئة OpenAI إلى أقرب فئات Llama Guard. حدد ثلاث فئات لا يتم تعيينها بشكل واضح.
4. قم بتصميم حزمة الإشراف لنشر مساعد التعليمات البرمجية (على سبيل المثال، GitHub Copilot). حدد الفئات الأكثر والأقل صلة واقترح قواعد مخصصة.
5. سينتهي مشرف محتوى Azure في فبراير 2027. خطط للترحيل إلى Azure AI أمان المحتوى. تحديد العنصر الأكثر خطورة في الهجرة.
