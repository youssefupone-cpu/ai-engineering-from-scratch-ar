# نمط البيرسبترون
يحسب الإدراك الحسي مجموعًا مرجحًا للمدخلات بالإضافة إلى التحيز، ثم يطبق دالة تدريجية لإنتاج مخرجات ثنائية. إنها الوحدة الأساسية للشبكات العصبية.
```
output = step(w1*x1 + w2*x2 + ... + wn*xn + bias)
```

## عندما يكفي إدراك واحد
- المشكلة قابلة للفصل خطيًا: يمكن للخط المستقيم (أو المستوى الزائد) أن يقسم الفئتين
- البوابات المنطقية: AND، OR، NOT، NAND
- قرارات بسيطة: "هل النتيجة أعلى من X؟"
- المصنفات الثنائية على البيانات التي تتجمع في منطقتين غير متداخلتين
## عندما تحتاج إلى طبقات متعددة
- المشكلة ليست قابلة للفصل خطيًا: لا يمكن لأي سطر واحد أن يفصل بين الفئات
- XOR ومشاكل التكافؤ
- أي مهمة تتطلب منطق "هذا وليس ذاك" (مجموعة من الشروط)
- تصنيف العالم الحقيقي: الصور والنصوص والصوت - دائمًا تقريبًا غير خطي
## قائمة مراجعة القرار
1. قم بتخطيط بياناتك أو فحصها. هل يمكنك رسم حدود مستقيمة واحدة بين الطبقات؟
   - نعم: يعمل الإدراك الفردي
   - لا: أنت بحاجة إلى طبقتين على الأقل
2. هل يمكن تقسيم المشكلة إلى AND/OR من القرارات الخطية الأبسط؟
   - يخبرك هذا التحليل بالحد الأدنى لبنية الشبكة
   - XOR = (A OR B) AND (NOT (A AND B)) = 3 إدراكات في طبقتين
3. بالنسبة للمشاكل التي تحتوي على أكثر من فئتين، تحتاج إلى مخرج واحد node لكل فصل
## قاعدة التدريب
```
error = expected - predicted
weight_new = weight_old + learning_rate * error * input
bias_new = bias_old + learning_rate * error
```

إذا كان التوقع صحيحا، فلن يتغير شيء. إذا كان الخطأ، تتغير الأوزان لتقليل الخطأ. هذا يعمل فقط مع الإدراك الحسي أحادي الطبقة. تتطلب الشبكات متعددة الطبقات الانتشار العكسي.
##أخطاء شائعة
- محاولة تعلم الأنماط غير الخطية باستخدام مُدرك واحد (لن يتقارب أبدًا)
- تحديد معدل التعلم مرتفع جدًا (تتأرجح الأوزان) أو منخفض جدًا (يستغرق التدريب وقتًا طويلاً)
- نسيان مصطلح التحيز (بدونه يجب أن تمر حدود القرار عبر الأصل)
- الخلط بين تقارب الإدراك الحسي (مضمون للبيانات القابلة للفصل خطيًا) وتقارب الشبكة العصبية العامة (غير مضمون)
