# SVM دليل اختيار النواة
يتم تعريف SVMs من خلال خيارين: النواة (التي تحدد شكل حدود القرار) ومعلمات التنظيم (التي تتحكم في المفاضلة بين عرض الهامش وأخطاء التصنيف). إن الحصول على هذه الأمور بشكل صحيح هو الفرق بين النموذج عديم الفائدة والنموذج القوي.
## قائمة مراجعة القرار
1. هل البيانات قابلة للفصل خطيًا (أو قريبة منها)؟
   - نعم: استخدم النواة الخطية. إنه أسرع وأكثر قابلية للتفسير.
   - لا: انتقل إلى الخطوة 2.
2. كم عدد الميزات مقابل العينات؟
   - الميزات >> العينات (على سبيل المثال، النص مع TF-IDF): استخدم النواة الخطية. غالبًا ما تكون البيانات عالية الأبعاد قابلة للفصل خطيًا. RBF يضيف التعقيد دون أي فائدة.
   - العينات >> الميزات (على سبيل المثال، البيانات الجدولية التي تحتوي على 10-50 ميزة): RBF kernel هو الاختيار الافتراضي.
3. هل من المتوقع أن تكون حدود القرار سلسة؟
   - حدود سلسة ومستمرة: RBF kernel
   - الحدود على شكل متعدد الحدود: نواة متعدد الحدود (يبدأ بالدرجة 2 أو 3)
   - تقترح معرفة المجال مصطلحات تفاعل محددة: نواة متعددة الحدود بدرجة مطابقة
4. ما حجم مجموعة البيانات؟
   - أقل من 10000 عينة: أي نواة تعمل، RBF هو الإعداد الافتراضي الآمن
   - 10000 إلى 100000: نواة خطية أو LinearSVC (الصيغة الأولية، O(n) لكل عصر)
   - أكثر من 100000: لا تستخدم النواة SVM. قم بالتبديل إلى SVM الخطي أو تعزيز التدرج أو الشبكات العصبية.
5. هل قمت بقياس الميزات؟
   - تتطلب SVMs تحجيم الميزات. قم دائمًا بالتوحيد القياسي (متوسط ​​صفر، تباين الوحدة) قبل التركيب. تشوه الميزات غير المقاسة هندسة الهامش.
## مخطط انسيابي لاختيار النواة
```
Start
  |
  v
Features > 1000 or features >> samples?
  Yes --> Linear kernel (LinearSVC for speed)
  No  --> Dataset < 10k samples?
            Yes --> Try RBF first (best general-purpose kernel)
            No  --> Linear kernel (kernel SVMs are O(n^2) to O(n^3))
```

إذا لم يعمل RBF بشكل جيد، فجرّب درجة متعددة الحدود 2-3. إذا فشل ذلك، فقد لا تكون المشكلة مناسبة لـ SVMs.
## ضبط C (التسوية)
يتحكم C في عقوبة سوء التصنيف. ويرتبط عكسيا بقوة التنظيم.
| قيمة ج | تأثير | متى تستخدم |
|---------|-------|-------------|
| 0.001 - 0.01 | هامش واسع، العديد من المخالفات مسموحة | بيانات صاخبة، نريد التعميم |
| 0.1 - 1.0 | متوازن | نطاق انطلاق جيد |
| 10 - 1000 | هامش ضيق ومخالفات قليلة | بيانات نظيفة، تحتاج إلى دقة عالية |
استراتيجية الضبط:
- ابدأ بـ C=1.0
- البحث على مقياس سجل: [0.001، 0.01، 0.1، 1، 10، 100، 1000]
- استخدم التحقق المتبادل لاختيار أفضل قيمة
- إذا كان أفضل C يقع على حافة النطاق الخاص بك، فقم بتوسيع النطاق في هذا الاتجاه
## ضبط جاما (RBF النواة)
تتحكم جاما في مدى وصول تأثير نقطة تدريب واحدة. وهو يحدد عرض غاوسي.
| قيمة جاما | تأثير | متى تستخدم |
|-------------|--------|-------------|
| صغير (0.001) | كل نقطة تؤثر على مساحة كبيرة. حدود سلسة وبسيطة | ميزات غير مناسبة أو قليلة |
| متوسط ​​(تلقائي: 1/n_features) | sklearn الافتراضي. نقطة انطلاق معقولة | الاستخدام العام |
| كبير (10+) | تؤثر كل نقطة على النقاط القريبة فقط. حدود معقدة ومتذبذبة | خطر التجهيز الزائد |
استراتيجية الضبط:
- ابدأ بـ gamma="scale" (1 / (n_features * X.var())، الافتراضي sklearn)
- البحث على مقياس سجل: [0.001، 0.01، 0.1، 1، 10]
- يميل انخفاض جاما + ارتفاع C إلى الإفراط في الاحتواء
- غاما عالية + منخفضة C تميل إلى عدم الملائمة
## ضبط مشترك C وغاما
تتفاعل C وغاما. قم دائمًا بضبطها معًا، وليس بشكل مستقل.
النهج الموصى به:
1. بحث شبكي خشن: C في [0.01، 0.1، 1، 10، 100]، جاما في [0.001، 0.01، 0.1، 1، 10] (25 مجموعة)
2. ابحث عن أفضل منطقة
3. البحث في الشبكة الدقيقة حول أفضل منطقة (على سبيل المثال، C في [5، 10، 20، 50]، جاما في [0.05، 0.1، 0.2])
4. استخدم التحقق المتبادل بخمسة أضعاف طوال الوقت
##أخطاء شائعة
- استخدام نواة RBF على البيانات المتفرقة عالية الأبعاد (الخطي أفضل وأسرع 100 مرة)
- نسيان قياس الميزات (الخطأ الوحيد الأكثر شيوعًا SVM)
- ضبط C بدرجة عالية جدًا على البيانات الصاخبة (يحفظ الضوضاء بدلاً من تعلم الحدود)
- استخدام النواة SVM على مجموعات بيانات تزيد عن 50 ألف عينة (وقت التدريب باهظ)
- عدم ضبط C وغاما معاً (يعوض كل منهما الآخر)
- التخلف عن درجة متعددة الحدود 5+ (التجاوز بقوة، حاول 2 أو 3 أولاً)
