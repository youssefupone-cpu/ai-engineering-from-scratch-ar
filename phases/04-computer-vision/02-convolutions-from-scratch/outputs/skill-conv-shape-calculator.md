# Conv Shape Calculator

مساعد حتمي للتخطيط أو تصحيح الأخطاء CNN. إعطاء شكل إدخال وقائمة بمواصفات الطبقة وأشكال التتبع والحقول المستقبلة وأعداد المعلمات دون تشغيل النموذج.

## When to use

- تصميم CNN جديد وتريد التحقق من كل عينة صغيرة تصل إلى حجم نظيف.
- قراءة ورقة وترجمة جدول معماريتها إلى كود.
- يتعطل العمود الفقري المُدرب مسبقًا بسبب عدم تطابق الشكل في رأس المصنف وتحتاج إلى معرفة الطبقة التي غيرت الحجم المكاني.
- مقارنة عمودين فقريين على كفاءة المعلمة قبل التدريب أيضاً.

## Inputs

- `input_shape`: `(C, H, W)`.
- `layers`: قائمة مرتبة لإملاءات الطبقة. يدعم كل من: - `{type: "conv", c_out, k, s, p, groups=1, bias=true}` - `{type: "pool", mode: "max"|"avg", k, s, p=0}` - `{type: "adaptive_pool", out_h, out_w}` - `{type: "flatten"}` - `{type: "linear", out_features, bias=true}`

## Steps

1. **تهيئة التتبع** باستخدام `(C, H, W)`، الحقل الاستقبالي `1`، الخطوة الفعالة `1`، المعلمات التراكمية `0`.

2. **لكل طبقة**، قم بالتحديث بهذا الترتيب: - حساب `C_out` (تحويل/خطي)، أو حمل `C_in` عبر (تجمع). - حساب الإخراج المكاني باستخدام `(H + 2P - K) / S + 1` للتحويل والتجميع، `out_h/out_w` للتجميع التكيفي، `(1, 1)` لتسوية شكل الإخراج `(C * H * W, 1, 1)` قبل الخطي، والعددية `1x1` للخطي. - تحديث المجال الاستقبالي والخطوة الفعالة: - التحويل/التجميع: `RF_new = RF_old + (K - 1) * effective_stride`، `effective_stride *= S`. - حمام السباحة التكيفي: تعامل مع حمام السباحة بـ `S = H_in / out_h` فعال (مقرب للأسفل). `RF_new = RF_old + (H_in - 1) * effective_stride_old`; `effective_stride *= S`. لاحظ أن التجمع التكيفي RF يساوي المدى المكاني الكامل السابق. - التسطيح / الخطي: RF والخطوة الفعالة لم تعد ذات معنى؛ قم بتجميدها إلى القيم قبل التسوية وحذفها من الصفوف اللاحقة. - حساب المعلمات: - التحويل: `C_out * (C_in / groups) * K * K + (C_out if bias else 0)`. - الخطي: `out_features * in_features + (out_features if bias else 0)`. - البلياردو والتسطيح: 0.

3. **اكتشف المشاكل** وقم بوضع علامة عليها: - حجم الإخراج غير صحيح (خطوة/حشوة غير محاذاة). - `H_out <= 0` قبل نهاية المكدس. - حقل استقبال يتجاوز حجم الإدخال (احتمال إهدار الحساب بعد تلك النقطة). - قفزات مفاجئة بمقدار 10x في معلمات كل طبقة تشير إلى خطة قناة خاطئة.

4. **التقرير** كجدول واحد:

```
idx  layer                C_in  C_out  K  S  P  H_out  W_out  RF    params     cum_params
1    conv 3x3 s=1 p=1     3     32     3  1  1  224    224    3     896        896
2    conv 3x3 s=2 p=1     32    64     3  2  1  112    112    7     18,496     19,392
3    pool max 2x2         64    64     2  2  0  56     56     11    0          19,392
...
```

5. **سطر الملخص**: نهائي `(C, H, W)`، حقل الاستقبال النهائي، إجمالي المعلمات، التحذيرات.

## Rules

- قم دائمًا بإرجاع الأعداد الصحيحة للأحجام المكانية. إذا كانت الصيغة تنتج عددًا غير صحيح، فقم بوضع علامة على أنها خطأ ولا تتجاهلها بصمت.
- عندما `groups > 1`، تحقق من `C_in % groups == 0` و `C_out % groups == 0`؛ وإلا خطأ.
- بالنسبة للتحويل العميق (`groups == C_in`)، قم بتسميته في العمود `layer` حتى يرى القارئ سبب انخفاض المعلمات.
- إذا قام المستخدم بتوفير BatchNorm أو طبقات التنشيط، فتجاهلها لأغراض الشكل ولكن قم بنقل المعلمات للأمام (`2 * C` لكل BatchNorm).
- لا تخمن أبدًا الإعدادات الافتراضية للحقول المفقودة. يلزم وجود `k`، `s`، `p` في كل تحويل وتجميع.
