# Advanced RAG Pattern

الأساسية RAG: تضمين الاستعلام -> بحث المتجهات -> top-k -> إنشاء.
متقدم RAG: تضمين الاستعلام + BM25 -> رتب الصمامات -> إعادة الترتيب -> أعلى k -> إنشاء.

```
query -> [vector search (top-50)] -+-> RRF fusion -> reranker (top-5) -> prompt -> LLM
                                   |
query -> [BM25 search (top-50)]  --+
```

## When to upgrade from basic RAG

- انخفاض جودة الاسترجاع إلى أقل من 70% Recall@5
- أبلغ المستخدمون عن إجابات خاطئة أو غير ذات صلة
- ينمو الجسم إلى أكثر من 100 ألف قطعة
- تستخدم الاستعلامات مفردات مختلفة عن المستندات
- أسئلة القفزات المتعددة تفشل باستمرار

## Implementation checklist

1. أضف فهرس BM25 إلى جانب فهرس المتجه
2. قم بإجراء كلا البحثين بالتوازي (أفضل 50 بحثًا لكل منهما)
3. الدمج مع دمج الرتبة المتبادلة (k=60)
4. إعادة ترتيب أفضل المرشحين باستخدام برنامج التشفير المتقاطع
5. احصل على المراكز الخمسة الأولى في المطالبة النهائية
6. إضافة تقييم الإخلاص على مجموعة اختبار

## Technique selection guide

- **البحث المختلط**: يستخدم دائمًا في الإنتاج. لا يكلف شيئًا إضافيًا في وقت الاستعلام.
- **إعادة الترتيب**: يُستخدم عندما يكون Recall@50 جيدًا ولكن Recall@5 سيئًا. يضيف الكمون 50-200 مللي ثانية.
- **HyDE**: يُستخدم عندما تكون الاستعلامات غامضة أو تستخدم مفردات مختلفة عن المستندات. إضافة مكالمة LLM واحدة.
- **الأجزاء الأصلية والفرعية**: يتم استخدامها عندما تفتقر الأجزاء الصغيرة إلى السياق بينما تؤدي الأجزاء الكبيرة إلى إضعاف الصلة.
- **تصفية البيانات الوصفية**: يتم استخدامها عندما تحتوي المجموعة على فئات واضحة (التاريخ، نوع المصدر، القسم).
- **تحليل الاستعلام**: يُستخدم للأسئلة متعددة القفزات التي تتطلب معلومات من مستندات متعددة.

## Common mistakes

- تشغيل BM25 والبحث المتجه باستخدام مجموعات قطع مختلفة (يجب عليهم البحث في نفس المجموعة)
- استخدام مجموعة صغيرة جدًا من المرشحين لإعادة الترتيب (العشرة الأوائل عدد قليل جدًا؛ استخدم أعلى 50)
- إضافة HyDE لكل استعلام (يساعد فقط عندما يكون عدم تطابق المفردات هو عنق الزجاجة)
- عدم تقييم التغييرات (قم بقياس Recall@k قبل وبعد كل تقنية)
- المبالغة في هندسة الخط pipe قبل قياس مكان فشله

## Evaluation workflow

1. أنشئ أكثر من 50 سؤال اختبار مع أجزاء إجابات معروفة
2. قم بقياس الاستدعاء عند 5 والاستدعاء عند 10 لكل طريقة استرجاع
3. بالنسبة للاستعلامات التي ينجح فيها الاسترجاع، قم بقياس مدى صدق الإجابات التي تم إنشاؤها
4. تتبع المقاييس أسبوعيًا مع نمو المجموعة
5. التحقيق في حالات الفشل الفردية قبل إضافة المزيد من التقنيات
