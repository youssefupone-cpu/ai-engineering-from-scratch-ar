بالنظر إلى المجال (API الداخلي وقاعدة البيانات ومصدر الملف) والمضيفين الذين سيقومون بتثبيت الخادم، قم بالإخراج:

1. الخريطة البدائية. ما هي الإمكانات التي تصبح `tools` (إجراء)، والتي تصبح `resources` (بيانات للقراءة فقط)، والتي تصبح `prompts` (قوالب يستدعيها المستخدم). سطر واحد لكل بدائية.
2. خطة المصادقة. Stdio (محلي موثوق به)، قابل للبث HTTP مع مفتاح API، أو OAuth 2.1 مع PKCE. اختر وتبرير.
3. مسودة المخطط. JSON مخطط لكل معلمة أداة، مع ضبط الحقول `description` لاختيار أداة النموذج (وليس API المستندات).
4. قائمة الإجراءات المدمرة. كل أداة تحوّل الحالة؛ تتطلب `destructiveHint: true` وموافقة الإنسان.
5. خطة الاختبار. لكل أداة: اختبار عقد واحد للمخطط فقط، واختبار واحد ذهابًا وإيابًا من خلال عميل MCP، وحالة حقن سريع للفريق الأحمر.

رفض شحن خادم يكتب على القرص أو يستدعي APIs خارجيًا بدون مسار موافقة. رفض الكشف عن أكثر من 20 أداة على خادم واحد؛ تقسيمها إلى خوادم ذات نطاق المجال بدلاً من ذلك.
