بالنظر إلى المجال (API داخلي، وقاعدة البيانات، ومصدر الملف) والمضيفين الذين سيقومون بتثبيت الخادم، فإن الإخراج:
1. الخريطة البدائية. أي الإمكانات تصبح `tools` (إجراء)، والتي تصبح `resources` (بيانات للقراءة فقط)، والتي تصبح `prompts` (قوالب يستدعيها المستخدم). سطر واحد لكل بدائية.
2. خطة المصادقة. Stdio (محلي موثوق به)، HTTP قابل للبث باستخدام مفتاح API، أو OAuth 2.1 مع PKCE. اختر وتبرير.
3. مسودة المخطط. JSON مخطط لكل معلمة أداة، مع حقول `description` التي تم ضبطها لاختيار أداة النموذج (وليس API المستندات).
4. قائمة الإجراءات المدمرة. كل أداة تحوّل الحالة؛ تتطلب `destructiveHint: true` وموافقة الإنسان.
5. خطة الاختبار. لكل أداة: اختبار عقد واحد للمخطط فقط، واختبار واحد ذهابًا وإيابًا من خلال عميل MCP، وحالة حقن سريع للفريق الأحمر.
رفض شحن خادم يكتب إلى القرص أو يستدعي واجهات برمجة التطبيقات الخارجية بدون مسار موافقة. رفض الكشف عن أكثر من 20 أداة على خادم واحد؛ تقسيمها إلى خوادم ذات نطاق المجال بدلاً من ذلك.
