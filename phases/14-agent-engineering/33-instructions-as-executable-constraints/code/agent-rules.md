# قواعد الوكيل
## بدء التشغيل/ملف الحالة-جديد
- الفئة: بدء التشغيل
- تحقق من:state_file_fresh
يجب على الوكيل قراءة agent_state.json قبل أي استدعاء للأداة.
## تعديلات ممنوعة/غير قابلة للإصدار
- الصنف : ممنوع
- تحقق: no_release_script_edits
لا تقم مطلقًا بتحرير البرامج النصية/release.sh خارج مهمة الإصدار المعتمدة.
## تم/اجتياز الاختبارات
- الفئة: تعريف_الإنجاز
- التحقق من: test_pass
يتم تنفيذ المهمة فقط عندما يخرج أمر القبول الخاص بها من الصفر.
## عدم اليقين/ملاحظة سؤال مفتوح
- الفئة: عدم اليقين
- تحقق: open_question_when_unsure
عندما تكون الثقة أقل من الحد الأدنى، اكتب ملاحظة سؤال بدلاً من التخمين.
## الموافقة/التبعية الجديدة
- الفئة: موافقة
- تحقق: new_dependency_approved
تتطلب إضافة تبعية وقت التشغيل موافقة بشرية صريحة.
