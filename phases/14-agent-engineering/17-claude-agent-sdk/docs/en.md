# Claude Agent SDK: Subagents and Session Store

> وكيل كلود SDK هو نموذج المكتبة لأداة كلود كود. أدوات مدمجة، وكلاء فرعيون لعزل السياق، خطافات، W3C انتشار التتبع، تكافؤ مخزن الجلسة. يُعد Claude Managed Agents البديل المستضاف للعمل غير المتزامن طويل الأمد.

** النوع: ** تعلم + بناء
** اللغات: ** بايثون (stdlib)
** المتطلبات الأساسية: ** المرحلة 14 · 01 (حلقة الوكيل)، المرحلة 14 · 10 (مكتبات المهارات)
**الوقت:** ~75 دقيقة

## Learning Objectives

- شرح الفرق بين العميل الأنثروبي SDK (الخام API) وكلود إيجنت SDK (شكل الحزام).
- وصف الوكلاء الفرعيين - التوازي وعزل السياق - ومتى يجب الوصول إليهم.
- قم بتسمية سطح مخزن جلسة Python SDK (`append`، `load`، `list_sessions`، `delete`، `list_subkeys`) ودور `--session-mirror`.
- تنفيذ أداة stdlib باستخدام الأدوات المضمنة، ونشر الوكيل الفرعي بسياق معزول، وخطافات دورة الحياة، ومخزن الجلسة.

## The Problem

الخام LLM API يمنحك رحلة ذهابًا وإيابًا. يحتاج وكيل الإنتاج إلى تنفيذ الأداة، وخوادم MCP، وخطافات دورة الحياة، وتوليد الوكيل الفرعي، واستمرارية الجلسة، وانتشار التتبع. يقوم Claude Agent SDK بشحن هذا الشكل كمكتبة - نفس الحزام الذي يستخدمه Claude Code، والذي يتم عرضه للوكلاء المخصصين.

## The Concept

### Client SDK vs Agent SDK

- **العميل SDK (`anthropic`).** الرسائل الأولية API. أنت تملك الحلقة، والأدوات، والدولة.
- **الوكيل SDK (`claude-agent-sdk`).** تنفيذ أداة مدمجة، اتصالات MCP، خطافات، نشر الوكيل الفرعي، مخزن الجلسة. حلقة كلود كود كمكتبة.

### Built-in tools

يشحن SDK أكثر من 10 أدوات خارج الصندوق: قراءة/كتابة الملفات، وshell، وgrep، وglob، وجلب الويب، والمزيد. يتم تسجيل الأدوات المخصصة عبر واجهة مخطط الأداة القياسية.

### Subagents

غرضان وثقتهما الأنثروبيك:

1. **التوازي.** تشغيل العمل المستقل بشكل متزامن. "ابحث عن ملف الاختبار لكل وحدة من هذه الوحدات العشرين" هو 20 مهمة فرعية متوازية.
2. **عزل السياق.** يستخدم الوكلاء الفرعيون نافذة السياق الخاصة بهم؛ النتائج فقط تعود إلى المنسق. يتم الحفاظ على ميزانية المنسق.

إضافات بايثون SDK الأخيرة: `list_subagents()`، `get_subagent_messages()` لقراءة نصوص الوكيل الفرعي.

### Session store

تكافؤ البروتوكول مع TypeScript:

- `append(session_id, message)` — إضافة دور.
- `load(session_id)` — استعادة المحادثة.
- `list_sessions()` — تعداد.
- `delete(session_id)` — مع التتالي إلى جلسات الوكيل الفرعي.
- `list_subkeys(session_id)` — قائمة بمفاتيح الوكيل الفرعي.

`--session-mirror` (علامة CLI) يعكس النص إلى ملف خارجي أثناء تدفقه، لتصحيح الأخطاء.

### Hooks

خطافات دورة الحياة التي يمكنك تسجيلها:

- `PreToolUse`، `PostToolUse` — استدعاءات البوابة أو أداة التدقيق.
- `SessionStart`، `SessionEnd` — الإعداد والهدم.
- `UserPromptSubmit` — التصرف بناءً على مدخلات المستخدم قبل أن يراها النموذج.
- `PreCompact` — يتم تشغيله قبل ضغط السياق.
- `Stop` — التنظيف عند خروج العميل.
- `Notification` — تنبيهات القناة الجانبية.

الخطافات هي الطريقة التي تضيف بها سير العمل المؤيد (مرجع منهج المرحلة 14) والأنظمة المماثلة سلوكًا شاملاً.

### W3C trace context

يمتد OTel نشطًا عند المتصل وينتشر في العملية الفرعية CLI عبر رؤوس سياق التتبع W3C. يظهر التتبع متعدد العمليات بالكامل كتتبع واحد في الواجهة الخلفية لديك.

### Claude Managed Agents

البديل المستضاف (رأس الإصدار التجريبي `managed-agents-2026-04-01`). عمل غير متزامن طويل الأمد، وتخزين مؤقت سريع مدمج، وضغط مدمج. مراقبة التجارة للبنية التحتية المدارة.

### Where this pattern goes wrong

- **النشر الزائد للوكيل الفرعي.** نشر 100 وكيل فرعي لـ 100 مهمة صغيرة. النفقات العامة تهيمن. دفعة بدلا من ذلك.
- **زحف الخطاف.** يضيف كل فريق خطافات؛ بالونات وقت بدء التشغيل. مراجعة الخطافات ربع سنوية.
- **تضخم الجلسة.** تتراكم الجلسات؛ الحجم ينمو. استخدم `list_sessions` + سياسة انتهاء الصلاحية.

## Build It

`code/main.py` ينفذ الشكل SDK في stdlib:

- `Tool`، `ToolRegistry` مع المدمج في `read_file`، `write_file`، `list_dir`.
- `Subagent` — سياق خاص، تشغيل معزول، إرجاع النتائج.
- `SessionStore` — إلحاق، تحميل، قائمة، حذف، list_subkeys.
- `Hooks` — run، before، context، compaction.
- عرض توضيحي: يقوم الوكيل الرئيسي بتوليد 3 عملاء فرعيين بالتوازي (كل منهم معزول)، ويجمع النتائج، ويستمر في الجلسة.

تشغيله:

```
python3 code/main.py
```

يُظهر التتبع عزل سياق الوكيل الفرعي (يظل حجم سياق المُنسق محدودًا)، وتنفيذ الخطاف، واستمرارية الجلسة.

## Use It

- **وكيل كلود SDK** لمنتجات كلود فيرست التي تريد شكل حزام كلود كود.
- **Claude Managed Agents** للعمل المستضاف غير المتزامن طويل الأمد.
- **OpenAI الوكلاء SDK** (الدرس 16) لـ OpenAI- النظيرات الأولى.
- **LangGraph + أدوات مخصصة** إذا كنت تريد جهاز الحالة على شكل رسم بياني بدلاً من ذلك.

## Ship It

`outputs/skill-claude-agent-scaffold.md` يدعم تطبيق Claude Agent SDK مع الوكلاء الفرعيين والخطافات ومخزن الجلسة ومرفق الخادم MCP وانتشار التتبع W3C.

## Exercises

1. أضف مولد وكيل فرعي يقوم بتجميع 20 مهمة في مجموعات مكونة من 5 وكلاء فرعيين متوازيين. قياس حجم سياق المنسق مقابل واحد لكل مهمة.
2. قم بتنفيذ خطاف `PreToolUse` يحدد معدل المكالمات `write_file` (5 في الدقيقة لكل جلسة). تتبع السلوك.
3. قم بتوصيل السلك `list_subkeys` لتقديم شجرة الوكيل الفرعي. كيف يبدو التعشيش العميق؟
4. قم بنقل اللعبة إلى حزمة Python الحقيقية. ما هي التغييرات في تسجيل الأداة؟
5. اقرأ مستندات Claude Managed Agents. متى يمكنك التبديل من الاستضافة الذاتية إلى المُدارة؟

## Key Terms

| مصطلح | ماذا يقول الناس | ماذا يعني في الواقع |
|------|----------------|-----------------------|
| الوكيل SDK | "كلود كود كمكتبة" | شكل الحزام: أدوات، MCP، خطافات، وكلاء فرعيون، متجر الجلسة |
| الوكيل الفرعي | "وكيل الطفل" | سياق منفصل، ميزانية خاصة؛ فقاعة النتائج تصل |
| متجر الجلسة | "محادثة DB" | استمر، وتحميل، وقائمة، وحذف المنعطفات مع تتالي الوكيل الفرعي |
| هوك | "رد دورة الحياة" | أداة ما قبل/ما بعد، الجلسة، الإرسال الفوري، الضغط، الإيقاف |
| W3C تتبع السياق | "تتبع العمليات المتقاطعة" | ينتشر النطاق الأصلي في CLI العملية الفرعية |
| الوكلاء المدارون | "تسخير مستضاف" | عمل غير متزامن طويل الأمد مستضاف بواسطة الإنسان |
| `--session-mirror` | "مرآة النص" | تتحول جلسة الكتابة إلى ملف خارجي أثناء الدفق |
| MCP الخادم | "سطح الأداة" | الأداة الخارجية/مصدر الموارد المرفق بالوكيل |
