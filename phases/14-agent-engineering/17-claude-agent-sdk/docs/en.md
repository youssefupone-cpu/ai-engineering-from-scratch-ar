# وكيل كلود SDK: الوكلاء الفرعيون ومخزن الجلسات
> وكيل Claude SDK هو نموذج المكتبة الخاص بأداة Claude Code. الأدوات المضمنة، والوكلاء الفرعيون لعزل السياق، والخطافات، ونشر التتبع W3C، وتكافؤ مخزن الجلسة. يُعد Claude Managed Agents البديل المستضاف للعمل غير المتزامن طويل الأمد.
** النوع: ** تعلم + بناء
** اللغات: ** بايثون (stdlib)
** المتطلبات الأساسية: ** المرحلة 14 · 01 (حلقة الوكيل)، المرحلة 14 · 10 (مكتبات المهارات)
**الوقت:** ~75 دقيقة
## أهداف التعلم
- شرح الفرق بين العميل الأنثروبي SDK (الخام API) ووكيل كلود SDK (شكل الحزام).
- وصف الوكلاء الفرعيين - التوازي وعزل السياق - ومتى يجب الوصول إليهم.
- قم بتسمية سطح مخزن جلسة Python SDK (`append`، `load`، `list_sessions`، `delete`، `list_subkeys`) ودور `--session-mirror`.
- تنفيذ أداة stdlib باستخدام الأدوات المضمنة، ونشر الوكيل الفرعي بسياق معزول، وخطافات دورة الحياة، ومخزن الجلسة.
## المشكلة
يمنحك LLM API الأولي رحلة واحدة ذهابًا وإيابًا. يحتاج وكيل الإنتاج إلى تنفيذ الأداة، وخوادم MCP، وخطافات دورة الحياة، وتوليد الوكيل الفرعي، واستمرارية الجلسة، ونشر التتبع. يقوم Claude Agent SDK بشحن هذا الشكل كمكتبة - وهو نفس الحزام الذي يستخدمه Claude Code، والذي يتم عرضه للوكلاء المخصصين.
##المفهوم
### العميل SDK مقابل الوكيل SDK
- **العميل SDK (`anthropic`).** الرسائل الأولية API. أنت تملك الحلقة، والأدوات، والدولة.
- **الوكيل SDK (`claude-agent-sdk`).** تنفيذ الأداة المضمنة، واتصالات MCP، والخطافات، وتوليد الوكيل الفرعي، وتخزين الجلسة. حلقة كلود كود كمكتبة.
### الأدوات المدمجة
يأتي SDK بأكثر من 10 أدوات خارج الصندوق: قراءة/كتابة الملفات، Shell، grep، glob، جلب الويب، والمزيد. يتم تسجيل الأدوات المخصصة عبر واجهة مخطط الأداة القياسية.
### الوكلاء الفرعيون
غرضان وثقتهما الأنثروبيك:
1. **التوازي.** تشغيل العمل المستقل بشكل متزامن. "ابحث عن ملف الاختبار لكل وحدة من هذه الوحدات العشرين" هو 20 مهمة فرعية متوازية.
2. **عزل السياق.** يستخدم الوكلاء الفرعيون نافذة السياق الخاصة بهم؛ النتائج فقط تعود إلى المنسق. يتم الحفاظ على ميزانية المنسق.
إضافات Python SDK الأخيرة: `list_subagents()`، `get_subagent_messages()` لقراءة نصوص الوكيل الفرعي.
### مخزن الجلسة
تكافؤ البروتوكول مع TypeScript:
- `append(session_id, message)` — أضف دورًا.
- `load(session_id)` — استعادة المحادثة.
- `list_sessions()` — تعداد.
- `delete(session_id)` — مع التتالي إلى جلسات الوكيل الفرعي.
- `list_subkeys(session_id)` — قائمة مفاتيح الوكيل الفرعي.
`--session-mirror` (علامة CLI) يعكس النص إلى ملف خارجي أثناء تدفقه، لتصحيح الأخطاء.
### خطافات
خطافات دورة الحياة التي يمكنك تسجيلها:
- `PreToolUse`، `PostToolUse` — استدعاءات البوابة أو أداة التدقيق.
- `SessionStart`، `SessionEnd` — الإعداد والهدم.
- `UserPromptSubmit` — التصرف بناءً على مدخلات المستخدم قبل أن يراها النموذج.
- `PreCompact` — يتم تشغيله قبل ضغط السياق.
- `Stop` — التنظيف عند خروج الوكيل.
- `Notification` — تنبيهات القناة الجانبية.
الخطافات هي الطريقة التي تضيف بها سير العمل المؤيد (مرجع منهج المرحلة 14) والأنظمة المماثلة سلوكًا شاملاً.
### W3C سياق التتبع
تنتشر امتدادات OTel النشطة عند المتصل في العملية الفرعية CLI عبر رؤوس سياق التتبع W3C. يظهر التتبع متعدد العمليات بالكامل كتتبع واحد في الواجهة الخلفية لديك.
### وكلاء كلود المُدارة
البديل المستضاف (رأس الإصدار التجريبي `managed-agents-2026-04-01`). عمل غير متزامن طويل الأمد، وتخزين مؤقت سريع مدمج، وضغط مدمج. مراقبة التجارة للبنية التحتية المدارة.
### أين يسير هذا النمط بشكل خاطئ
- **النشر الزائد للوكيل الفرعي.** نشر 100 وكيل فرعي لـ 100 مهمة صغيرة. النفقات العامة تهيمن. دفعة بدلا من ذلك.
- **زحف الخطاف.** يضيف كل فريق خطافات؛ بالونات وقت بدء التشغيل. مراجعة الخطافات ربع سنوية.
- **تضخم الجلسة.** تتراكم الجلسات؛ الحجم ينمو. استخدم `list_sessions` + سياسة انتهاء الصلاحية.
## بنائها
`code/main.py` يطبق الشكل SDK في stdlib:
- `Tool`، `ToolRegistry` مع `read_file` المضمن، `write_file`، `list_dir`.
- `Subagent` — سياق خاص، تشغيل معزول، إرجاع النتائج.
- `SessionStore` — إلحاق، تحميل، قائمة، حذف، list_subkeys.
- `Hooks` — `pre_tool_use`، `post_tool_use`، `session_start`، `session_end`.
- عرض توضيحي: يقوم الوكيل الرئيسي بتوليد 3 عملاء فرعيين بالتوازي (كل منهم معزول)، ويجمع النتائج، ويستمر في الجلسة.
تشغيله:
```
python3 code/main.py
```

يُظهر التتبع عزل سياق الوكيل الفرعي (يظل حجم سياق المُنسق محدودًا)، وتنفيذ الخطاف، واستمرارية الجلسة.
## استخدمه
- **وكيل كلود SDK** لمنتجات Claude-first التي تريد شكل حزام Claude Code.
- **Claude Managed Agents** للعمل المستضاف غير المتزامن طويل الأمد.
- **OpenAI الوكلاء SDK** (الدرس 16) لـ OpenAI-النظيرات الأولى.
- **LangGraph + أدوات مخصصة** إذا كنت تريد جهاز الحالة على شكل رسم بياني بدلاً من ذلك.

## تمارين
1. أضف مولد وكيل فرعي يقوم بتجميع 20 مهمة في مجموعات مكونة من 5 وكلاء فرعيين متوازيين. قياس حجم سياق المنسق مقابل واحد لكل مهمة.
2. قم بتنفيذ خطاف `PreToolUse` الذي يحدد معدل `write_file` من المكالمات (5 في الدقيقة لكل جلسة). تتبع السلوك.
3. قم بتوصيل `list_subkeys` لتقديم شجرة الوكيل الفرعي. كيف يبدو التعشيش العميق؟
4. قم بنقل اللعبة إلى حزمة Python الحقيقية `claude-agent-sdk`. ما هي التغييرات في تسجيل الأداة؟
5. اقرأ مستندات Claude Managed Agents. متى يمكنك التبديل من الاستضافة الذاتية إلى المُدارة؟
