بالنظر إلى وقت التشغيل المستهدف (Python async، Python sync، Node، Rust async، Go) وقائمة الأدوات (الاسم، مخطط الإدخال، القابل للاستدعاء)، قم بإنتاج حلقة وكيل ReAct التي تكون صحيحة من المحاولة الأولى.
ينتج:
1. نوع المخزن المؤقت للرسائل مع الأدوار {المستخدم، المساعد، الأداة، النهائي} والمخطط الذي يتوقعه الموفر الهدف (الكتل الأنثروبي `tool_use` / `tool_result`، OpenAI رسائل استدعاء الوظائف، والاستجابات API قناة الاستدلال). لا تقم أبدًا بتبديل المخططات بصمت بين مقدمي الخدمة.
2. سجل أداة بالاسم -> إرسال قابل للاستدعاء، والتحقق من صحة الإدخال، ونتيجة مكتوبة. يجب اكتشاف الأخطاء وتحويلها إلى سلاسل مراقبة، وعدم رفعها إلى الحلقة أبدًا.
3. حلقة يتم تشغيلها حتى أحد: إجراء `finish` الصريح، أو عدم استدعاء أي أداة في دور المساعد، أو الحد الأقصى للدورات، أو الحد الأقصى لإجمالي الرموز المميزة، أو رحلة حاجز الحماية. اختر محطة رئيسية واحدة بالضبط؛ والبعض الآخر أحزمة أمان.
4. ميزانية دورية تتناسب مع فئة المهمة - مهمة قصيرة 10، استخدام الكمبيوتر 200، بحث عميق 400. حدد الاختيار بوضوح.
5. سجل تتبع يسجل فيه كل فكرة وفعل وملاحظة وسبب توقف. قم بإصدار امتدادات OpenTelemetry GenAI (`invoke_agent`، `tool_call`) عندما يكون وقت التشغيل موجودًا OTel SDK.
الرفض الصارم:
- حلقات بدون غطاء دوران. هذه مشكلة موثوقية وليست مسألة تحسين.
- ابتلاع أخطاء الأداة إلى ملاحظة فارغة. يجب أن يرى النموذج نص الفشل حتى يتمكن من التصحيح.
- التعامل مع المحتوى المسترد باعتباره تعليمات موثوقة. جميع مخرجات الأداة هي مدخلات غير موثوق بها — فقط رسالة المستخدم هي التي تحمل الإذن (راجع OpenAI CUA المستندات).
- خلط مقدمي الخدمات بدون طبقة ترجمة المخطط. يحتوي Anthropic وOpenAI على مخططات أدوات وأشكال رسائل متباينة.
قواعد الرفض:
- إذا كان الهدف هو "لا يوجد إطار عمل، bash فقط"، ارفض وأوصِ على الأقل بمخطط رسالة مكتوبة؛ حلقات الوكيل معرضة جدًا للخطأ بالنسبة لغراء القشرة غير المكتوب.
- إذا طلب المستخدم "إعادة المحاولة التلقائية عند استدعاء الأداة الفاشلة دون تقديم تعليقات إلى النموذج"، فارفض. يجب أن تتم عمليات إعادة المحاولة عبر النموذج (CRITIC/Self-Refine، الدرس 05) أو أن تكون جزءًا من عقد عدم القدرة الخاص بالأداة.
- إذا كانت قائمة الأدوات تحتوي على أداة تدميرية دون تأكيد بشري في الحلقة، فارفضها وأشر إلى الدرس 09 (الأذونات + وضع الحماية).
المخرجات: ملف واحد لكل لغة مستهدفة بالإضافة إلى `README.md` يشرح اختيار شرط الإيقاف، ومبرر الميزانية، وتتبع عملي يوضح ملاحظة التفكير والإجراء لكل خطوة. اختتم بـ "ما يجب قراءته بعد ذلك" مع الإشارة إلى الدرس 02 (تخطيط ReWOO) إذا كانت المهمة بعيدة المدى، أو الدرس 03 (التأمل) إذا كانت المهمة متكررة للسابقة، أو الدرس 27 (الإدخال الفوري) إذا كانت الأدوات تلامس محتوى غير موثوق به.
