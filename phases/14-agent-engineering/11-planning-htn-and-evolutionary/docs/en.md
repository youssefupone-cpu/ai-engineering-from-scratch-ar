# Planning with HTN and Evolutionary Search

> يتعامل التخطيط الرمزي مع الحالات التي تكون فيها الخطة صحيحة. يتعامل البحث التطوري عن الكود مع الحالات التي تكون فيها وظيفة اللياقة البدنية قابلة للتحقق آليًا. يُظهر ChatHTN (2025) وAlphaEvolve (2025) ما يفتحه كل منهما عند إقرانه بـ LLM.

**النوع:** بناء
** اللغات: ** بايثون (stdlib)
** المتطلبات الأساسية: ** المرحلة 14 · 02 (ReWOO والتخطيط والتنفيذ)
**الوقت:** ~75 دقيقة

## Learning Objectives

- شرح شبكات المهام الهرمية: المهام، الأساليب، العوامل، الشروط المسبقة، التأثيرات.
- وصف حلقة ChatHTN المختلطة - البحث الرمزي مع التحلل الاحتياطي LLM.
- اشرح حلقة AlphaEvolve التطورية ولماذا تعمل فقط مع مقيم برمجي.
- تنفيذ مخطط لعبة HTN بالإضافة إلى بحث تطوري للعبة في stdlib.

## The Problem

تغطي ReWOO (الدرس 02) وPlan-and-Execute وReAct معظم عمليات تخطيط الوكلاء. حالتان لا يغطيهما جيدًا:

1. **خطط يمكن إثبات صحتها.** الجدولة، ومسار الرحلة، وسير عمل الامتثال - يجب أن تكون الخطة سليمة من خلال البناء. خطة LLM بطلاقة والتي تهلوس أحيانًا بخطوة غير مقبولة.
2. **تحسينات باستخدام وظيفة اللياقة البدنية التي يمكن التحقق منها آليًا.** ضرب المصفوفة، والجدولة الاستدلالية، وتمريرات المترجم - الهدف ليس "الخطة الصحيحة" ولكن "الخطة الأفضل".

HTN التخطيط وAlphaEvolve يحلان المشكلتين المختلفتين. كلاهما يستخدم LLMs كمكبرات صوت، وليس بدائل.

## The Concept

### Hierarchical Task Networks

HTN هو:

- **المهام** — مركبة (متحللة) وبدائية (قابلة للتنفيذ مباشرة).
- **الطرق** — طرق تقسيم مهمة مركبة إلى مهام فرعية، بشروط مسبقة.
- **المشغلون** — إجراءات بدائية ذات شروط مسبقة وتأثيرات.
- **الدولة** — مجموعة من الحقائق.

التخطيط: بالنظر إلى مهمة هدف وحالة أولية، ابحث عن تحليل إلى مشغلين بدائيين يتم استيفاء شروطهم المسبقة بالتسلسل.

HTN أقدم من LLMs ولا يزال مرجعًا للخطط التي يمكن إثبات صحتها.

### ChatHTN (Gopalakrishnan et al., 2025)

ChatHTN (arXiv:2505.11814) يتداخل مع HTN الرمزي مع LLM الاستعلامات:

1. حاول تحليل المهمة المركبة الحالية بالطرق الموجودة.
2. إذا لم يتم تطبيق أي طريقة، اسأل LLM: "كيف ستتحلل `task` في الحالة `s`؟"
3. قم بترجمة الرد LLM إلى مهام فرعية للمرشح.
4. التحقق من صحة مخطط المشغل؛ رفض التحليلات غير صالحة.
5. العودية.

الادعاء المركزي للورقة: كل خطة يتم إنتاجها تكون سليمة بشكل مؤكد لأن اقتراحات LLM تدخل فقط كتحليلات للمرشحين، وليس كتعديلات مباشرة للخطة. الطبقة الرمزية تمتلك الصواب؛ يقوم LLM بتوسيع مكتبة الطريقة.

يضيف أسلوب التعلم عبر الإنترنت (OpenReview `gwYEDY9j2x`، 2025 متابعة) متعلمًا يعمم التحلل الناتج عن LLM عن طريق الانحدار — مما يؤدي إلى قطع LLM تكرار الاستعلام حتى 75%.

### AlphaEvolve (Novikov et al., 2025)

AlphaEvolve (arXiv:2506.13131، DeepMind، يونيو 2025) هو وحش مختلف: بحث عن الكود التطوري يتم تنسيقه بواسطة مجموعة Gemini 2.0 Flash/Pro.

Loop:

1. ابدأ ببرنامج أولي + مقيم برمجي (يُرجع درجة اللياقة البدنية).
2. مجموعة LLMs تقترح الطفرات.
3. تشغيل الطفرات من خلال المقيم.
4. حافظ على الأفضل؛ تحور مرة أخرى.

الانتصارات المنشورة:

- أول تحسين على Strassen في عملية ضرب المصفوفات المعقدة 4×4 خلال 56 عامًا (48 عملية ضرب عددية).
- تم استرداد 0.7% من حسابات Google من خلال أداة جدولة Borg الإرشادية.
- تسريع برنامج FlashAttention بنسبة 32% على أعباء العمل الحدودية.

القيد الصعب: يجب أن تكون وظيفة اللياقة البدنية قابلة للفحص آليًا. البحث التطوري على الإجابات النثرية لا يتقارب.

### When to use which

| فئة المشكلة | استخدم | لماذا |
|---------------|-----|-----|
| الجدولة مع القيود الصعبة | HTN + شاتHTN | سلامة اثبات |
| تحسين المترجم | ألفا تتطور | اللياقة البدنية التي يمكن التحقق منها آليًا |
| تنفيذ مهمة متعددة الخطوات | رد فعل / ReWOO | LLM في الحلقة، لا توجد ضمانات رسمية |
| تحسين الكود بالاختبارات | ألفا تتطور | الاختبارات هي المقيم |
| أتمتة مرتبطة بالسياسة | HTN | الشروط المسبقة سياسة التشفير |

### Where this pattern goes wrong

- **HTN بدون عوامل تشغيل.** بدون مخططات الشروط المسبقة/التأثيرات، تنهار مطالبة السلامة. يتطلب "LLM يقترح التحلل" الخاص بـ ChatHTN أن يرفض المخطط التحركات غير الصالحة.
- **AlphaEvolve بدون مقيم حقيقي.** "اسأل LLM إذا كان الكود أفضل" ليست وظيفة لياقة. يجب أن يكون المقيم حتميًا وسريعًا.
- **الإفراط في الهندسة.** لا تحتاج معظم مهام الوكيل أيضًا. قم بالوصول إلى ReAct أو ReWOO أولاً.

## Build It

`code/main.py` ينفذ لعبتين:

- مخطط stdlib HTN يحتوي على عوامل التشغيل والأساليب والشروط المسبقة والتأثيرات و `LLMFallbackFallback` الذي يبدأ عندما لا تتطابق أي طريقة مع مهمة مركبة. "LLM" عبارة عن محلل مكتوب بحيث يعمل المخطط دون اتصال بالإنترنت.
- بحث تطوري stdlib عبر البرامج الحسابية: قم بتنمية التعبيرات التي يقلل ناتجها `|f(x) - target|` عبر مجموعة اختبار. المقيم حتمي.

تشغيله:

```
python3 code/main.py
```

يُظهر التتبع مخطط HTN وهو يقوم بتحليل مهمة مركبة (مع خطة متوسطة LLM احتياطية) وتتقارب الحلقة التطورية عند تعبير مستهدف.

## Use It

- **HTN المخططون** — `pyhop`، `SHOP3`، أو أنشئ مخططًا خاصًا بك لتنفيذ السياسة الخاصة بالمجال.
- **ChatHTN** — رمز البحث؛ النمط (رمزي + LLM احتياطي) ينفذ بشكل نظيف إلى أي مخطط HTN.
- **AlphaEvolve** — ورقة DeepMind؛ النمط (المجموعة + المقيم) قابل للتكرار. OpenEvolve والشوكات مفتوحة المصدر المشابهة آخذة في الظهور.
- **أطر عمل الوكيل** — لا يتم شحن HTN أو AlphaEvolve من الدرجة الأولى حتى الآن. قم ببنائه كوكيل فرعي أو عامل في الخلفية.

## Ship It

`outputs/skill-hybrid-planner.md` يُنشئ سقالة مخطط هجينة (HTN أو تطورية) مع تحديد نطاق الدور LLM بشكل واضح.

## Exercises

1. قم بتوسيع مخطط HTN من خلال التراجع: عندما تفشل الحالة اللاحقة للمشغل في وقت التشغيل، قم بالتراجع وجرب الطريقة التالية.
2. أضف ذاكرة تخزين مؤقت للطريقة LLM إلى ChatHTN: عندما يقوم LLM بتفكيك المهمة `T` في نمط الحالة `P`، قم بتخزين النتيجة. أعد التحقق من مكتبة الطريقة أولاً في المكالمة التالية.
3. استبدل مقيم البحث التطوري بمجموعة اختبار حقيقية. تطوير وظيفة فرز تجتاز 20 حالة اختبار؛ تقرير الأجيال إلى التقارب.
4. اقرأ ملاحظات تصميم مقيم AlphaEvolve. صمم مقيمًا للمجال الذي يهمك (SQL تحسين الاستعلام، تقليل مجموعة الاختبار، النشر YAML).
5. اجمع: استخدم HTN لتحليل مهمة مركبة إلى مهام فرعية، ثم استخدم البحث التطوري على العامل البدائي لكل مهمة فرعية. أين يلمع، أين يبالغ في الهندسة؟

## Key Terms

| مصطلح | ماذا يقول الناس | ماذا يعني في الواقع |
|------|----------------|-----------------------|
| HTN | "المخطط الهرمي" | تحليل المهام مع العوامل والشروط المسبقة والتأثيرات |
| الطريقة | "قاعدة التحلل" | طريقة تقسيم المهمة المركبة إلى مهام فرعية |
| المشغل | "العمل البدائي" | خطوة ملموسة مع الشرط والتأثير |
| شات اتش تي ان | "LLM + HTN" | المخطط الرمزي يسأل LLM عندما لا توجد طريقة متطابقة |
| ألفا تتطور | "البحث عن الكود التطوري" | مجموعة LLMs رمز التحوير؛ المقيم الحتمي يختار |
| وظيفة اللياقة البدنية | "المقيم" | درجة حتمية يمكن التحقق منها آليًا على المخرجات |
| طريقة التعلم عبر الإنترنت | "التحلل LLM مخبأة" | تخزين + تعميم خطط LLM لخفض تكلفة الاستعلام |
