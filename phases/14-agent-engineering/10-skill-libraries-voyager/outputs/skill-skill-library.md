بالنظر إلى وقت التشغيل المستهدف والمجال، قم بإنتاج مكتبة مهارات تدعم مكونات Voyager الثلاثة: ربط المنهج، ومخزن المهارات القابل للاسترجاع، والتحسين التكراري.

Produce:

1. اكتب `Skill` مع `name`، `description`، `code`، `version`، `tags`، `depends_on`، `history`. كل كتابة تسجل الكود السابق.
2. `SkillLibrary` مع `register(skill, dedup=True)` (جديد أو نتوء الإصدار)، `search(query, top_k, tag_filter)`، `get(name)`، `topo_order(name)` (دقة العمق)، `execute(name, context)` (تشغيل طوبولوجي).
3. الاسترجاع MUST استخدم تضمين التشابه أو BM25، وليس LLM التسجيل على المكتبة الكاملة. LLM يُسمح بإعادة الترتيب في القائمة المختصرة لـ top-k.
4. التنفيذ MUST التقاط الاستثناءات لكل مهارة وإدراجها في التتبع كملاحظات يمكن أن تستهلكها حلقة التحسين.
5. خطاف التحسين: بعد فشل `execute`، يجمع وقت التشغيل (المهمة، اسم_المهارة، الخطأ، env_state)، ويمررها إلى النموذج، ويستدعي `register` على المهارة المعاد كتابتها. المطبات الإصدار. التاريخ يحافظ على الكود القديم.

الرفض الصارم:

- مكتبة حيث المهارات عبارة عن سلاسل نثرية وليست كود. المهارات قابلة للتنفيذ. النثر ينتمي إلى `description`.
- تكوين بدون فرز طوبولوجي. العمق أولاً دون الكشف عن الدورة فواصل على مهارات DAGs.
- النسخة الصامتة للكتابة. كل تحسين MUST يضغط `version` ويدفع الكود القديم إلى `history` للتدقيق.

قواعد الرفض:

- إذا لم يكن وقت التشغيل المستهدف يحتوي على صندوق رمل لتنفيذ المهارات، فارفض المجالات التي تمس فيها المهارات أنظمة الإنتاج. يلزم وجود صندوق رمل (الدرس 09 مبادئ) قبل الشحن.
- إذا طلب المستخدم "إعادة المحاولة التلقائية عند كل فشل بدون تحسين"، قم بالرفض. تؤدي إعادة المحاولة دون تحسين إلى تضخيم الخطأ؛ لا إصلاحه.
- إذا تجاوزت المكتبة حوالي 200 مهارة مع الاسترجاع الثابت، ارفض تسميتها "جاهزة للإنتاج". قم بإضافة عوامل تصفية العلامات ومساحات الأسماء الهرمية أولاً.

الإخراج: `skill.py`، `library.py`، `execute.py`، `refine.py`، و `README.md` يشرح قاعدة الحذف والواجهة الخلفية للاسترجاع ومطالبة التحسين وسياسة الإصدار. اختتم بـ "ما يجب قراءته بعد ذلك" بالإشارة إلى الدرس 17 لـ Claude Agent SDK التكامل، أو الدرس 16 لـ OpenAI الوكلاء SDK ترجمة الأدوات، أو الدرس 30 لتقييم جودة مكتبة المهارات.
