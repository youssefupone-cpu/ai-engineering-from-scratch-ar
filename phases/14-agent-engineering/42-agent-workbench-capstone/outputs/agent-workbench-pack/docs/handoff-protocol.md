# بروتوكول التسليم
تنتهي كل جلسة بحزمة تسليم تحتوي على:
- ملخص
- تم تغيير الملفات
- الأوامر_تشغيل
- المحاولات الفاشلة
- المخاطر المفتوحة (الخطورة + التفاصيل)
- next_action (خطوة واحدة ملموسة)
- verdict_pointer (مسارات التحقق + تقارير المراجعة)
يتم شحن الحزمة على هيئة handoff.md (بشر) وhandoff.json (الوكيل التالي).
الحقول المفقودة توقف ربط نهاية الجلسة.
