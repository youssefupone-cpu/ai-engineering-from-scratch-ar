# سياسة الموثوقية
تمتص طاولة العمل أوضاع الفشل المتكررة الخمسة في الصناعة:
1. فعل هلوسة - تم اكتشافه بواسطة مجموعة القواعد + بوابة التحقق.
2. زحف النطاق - تم اكتشافه من خلال فحص فرق عقد النطاق.
3. الأخطاء المتتالية - تم اكتشافها من خلال سجلات الملاحظات + رفض الخروج.
4. فقدان السياق - يتم امتصاصه بواسطة ذاكرة الريبو؛ الدردشة ليست مصدر الحقيقة.
5. إساءة استخدام الأداة - تم اكتشافها من خلال بُعد التحقق الخاص بقواعد تقييم المراجع.
يتم فرض السياسة من خلال بوابة التحقق. تم توقيع مسار التجاوز
ومدققة؛ لا يمكن للوكلاء تجاوز أنفسهم.
