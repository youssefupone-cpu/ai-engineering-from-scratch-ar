# عنوان المراجع
خمسة أبعاد، وسجل 0 إلى 2.
1. تناسب المشكلة - هل أدى التغيير إلى حل المهمة كما هو مذكور؟
2. انضباط النطاق – هل كانت التعديلات مقتصرة على العقد؟
3. الافتراضات – هل الافتراضات الخفية مكتوبة؟
4. جودة التحقق – هل القبول يثبت الهدف بالفعل؟
5. الاستعداد للتسليم – هل يمكن للجلسة التالية أن تبدأ بشكل نظيف؟
المجموع >= 7 بدون أصفار: ناجح. المجموع 5-6: فشل بسيط. أقل من 5 أو أي صفر: فشل ذريع.
