# Agent Workbench Pack

منضدة العمل المنسدلة لأي ريبو يريد عمل وكيل موثوق به.

## What you get

- `AGENTS.md` جهاز توجيه قصير في بقية الحزمة.
- `docs/` القواعد، سياسة الموثوقية، بروتوكول التسليم، قواعد تقييم المراجع.
- `schemas/` JSON مخططات عقد الولاية والمجلس والنطاق.
- `scripts/` الحرف الأول، مشغل الملاحظات، بوابة التحقق، مولد التسليم.
- `bin/install.sh` المثبت العاجز.

## Quickstart

```
bin/install.sh
$EDITOR task_board.json
python3 scripts/init_agent.py
```

## Versioning

الملف `VERSION` هو العقد. المطبات الكبرى تتطلب هجرة الدولة.
