# AGENTS.md

أنت تعمل داخل مستودع يتم تشغيله باستخدام منصة عمل الوكيل.

اقرأ هذه قبل التصرف:

1. `agent_state.json` — حيث توقفت الجلسة الأخيرة.
2. `task_board.json` — ما هو في الرحلة، ما هو التالي.
3. `docs/agent-rules.md` — بدء التشغيل، ممنوع، تم، عدم اليقين، الموافقة.
4. `docs/reliability-policy.md` — أوضاع الفشل التي تم تصميم طاولة العمل هذه لاستيعابها.
5. `docs/handoff-protocol.md` — ما الذي يجب أن تنتجه نهاية الجلسة.
6. `docs/reviewer-rubric.md` — كيف يتم الحكم على العمل المكتمل.

أمر التحقق: راجع `acceptance_criteria` في المهمة النشطة على اللوحة.

إصدار الحزمة: 1.0.0
