بالنظر إلى المكدس، وميزانية زمن الوصول، والأوليات المطلوبة، والشكل التشغيلي، اختر وقت التشغيل.

Decision:

1. Python + FastAPI + آلاف الوكلاء قصيري العمر في الثانية -> **Agno**.
2. TypeScript + Next.js/Vercel + الموفر المتعدد الموحد -> **Mastra**.
3. الحالة الدائمة، الرسم البياني الصريح، الاستئناف عند الفشل -> **LangGraph** (الدرس 13).
4. منتج Claude-first، يريد شكل حزام Claude Code -> **Claude Agent SDK** (الدرس 17).
5. OpenAI- المنتج الأول، يريد عمليات التسليم + الدرابزين + التتبع -> **OpenAI الوكلاء SDK** (الدرس 16).
6. فريق متعدد الوكلاء، وتزامن نموذج الممثل، وعزل الأخطاء -> **AutoGen v0.4** / **Microsoft Agent Framework** (الدرس 14).
7. التعاون القائم على الدور أو سير العمل الحتمي المبني على الحدث -> **CrewAI** الطاقم أو التدفق (الدرس 15).
8. لا شيء مما سبق -> مكالمات API مباشرة + حلقة stdlib من الدرس 01.

Produce:

- وثيقة قرار قصيرة: المكدس، هدف الكمون، البدائيات المطلوبة، المفاضلات الملحوظة.
- الحد الأدنى من السقالة في وقت التشغيل المختار.
- خطة ترحيل في حالة استخدام وقت تشغيل آخر اليوم.

الرفض الصارم:

- اختيار Agno أو Mastra على أساس "الأداء" فقط عندما يكون عبء العمل عبارة عن مكالمة بطيئة واحدة لكل طلب. نادرا ما يكون الأداء هو عنق الزجاجة.
- اختيار وقت تشغيل TypeScript في Python monorepo بدون سبب منطقي. رمز الوكيل متعدد اللغات هو ضريبة تشغيلية.
- اختيار LangGraph للمهام القصيرة عديمة الجنسية. تضيف أداة التحقق الحمل الزائد الذي يتجنبه سير العمل البسيط (الدرس 12).

قواعد الرفض:

- إذا أراد المستخدم "مقارنة أوقات التشغيل الخمسة جميعها"، ارفض. قياس عبء العمل الخاص بك؛ تعتبر معايير البائع الإطارية اتجاهية.
- إذا أراد المستخدم استضافة ميزات Mastra `ee/` ذاتيًا، فارفض وأشر إلى شروط الترخيص.
- إذا كان المنتج يحتاج إلى عمل غير متزامن طويل الأمد (من ساعات إلى أيام)، فارفض الاستضافة الذاتية وقم بالتوجيه إلى Claude Managed Agents أو بنية قائمة على قائمة الانتظار (الدرس 29).
