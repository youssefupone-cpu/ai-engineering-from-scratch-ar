# المهمة - ذاكرة الريبو والحالة الدائمة
## الهدف
قام المؤلف JSON بمخططات `agent_state.json` و `task_board.json` ببناء `StateManager` الذي يقوم بالتحميل والتحقق من الصحة والتحويل والكتابة ذريًا، وإثبات رحلة الذهاب والإياب عبر دورتين.
## المدخلات
- شكل طاولة العمل المكونة من ثلاثة ملفات من الدرس 32
- أداة التحقق من صحة stdlib فقط والتي تغطي النوع والتعداد والنمط والعناصر المطلوبة
## التسليمات
- `agent_state.schema.json` و`task_board.schema.json` بجوار الرمز
- `StateManager.load`، `StateManager.update`، `StateManager.commit` مع الكتابة المؤقتة وإعادة التسمية
- تشغيل تجريبي يغير الحالة عبر دورتين ويعيد التحميل بشكل نظيف
##القبول
- `python3 code/main.py` يخرج من الصفر
- تم رفض الكتابة السيئة (حقل مطلوب مفقود، التعداد غير صالح)، ولم يتم استمرارها
- `workdir/agent_state.json` بعد التحقق من صحة التشغيل مقابل المخطط
## خارج النطاق
- SQLite أو الواجهات الخلفية للتخزين الخارجي. الملف المحلي هو الدرس.
- نقاط تفتيش LangGraph وكتل ذاكرة Letta. نفس الفكرة، تخزين مختلف؛ خارج النطاق هنا.
