بالنظر إلى الهدف (لعبة المعلومات المثالية / المعلومات غير الكاملة / أتاري / LLM الاستدلال / التوافقي)، فإن الإخراج:
1. ملائمة البيئة. قواعد معروفة؟ ماركوف؟ مؤشر ستوكاستيك؟ متعدد الوكيل؟ يُعلم AlphaZero وMuZero وGRPO.
2. استراتيجية البحث. MCTS (PUCT مع ما تم تعلمه مسبقًا)، أو عينة Gumbel، أو الأفضل من بين N، أو لا شيء.
3. خطة اللعب الذاتي. لعب ذاتي / دوري / بيانات غير متصلة بالإنترنت / تم إنشاؤها بواسطة أداة التحقق.
4. إشارة الهدف. نتيجة اللعبة / مكافأة التحقق / التفضيل / النموذج المستفادة. تشمل خطة المتانة.
5. التشخيص. معدل الفوز مقابل خط الأساس، منحنى ELO، معدل نجاح المدقق، KL للرجوع إليه.
ارفض AlphaZero في الألعاب ذات المعلومات غير الكاملة (الطريق إلى CFR). ارفض GRPO بدون مدقق موثوق به. ارفض أي لعبة-RL pipeline بدون مجموعة خصم أساسية ثابتة (اللعب الذاتي ELO غير معاير بخلاف ذلك).
