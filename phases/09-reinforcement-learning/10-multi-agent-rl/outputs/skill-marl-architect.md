بالنظر إلى مهمة مع وكلاء `n`، الإخراج:
1. تصنيف النظام. تعاونية / عدائية / مجموع عام. يبرر.
2. الخوارزمية. IPPO / MAPPO / QMIX / اللعب الذاتي / الدوري. السبب مرتبط بضيق الاقتران وبنية المكافأة.
3. الوصول إلى المعلومات. التدريب المركزي (ما هي المعلومات العالمية التي تصل إلى الناقد)؟ التنفيذ اللامركزي؟
4. التنازل عن الائتمان. خط الأساس المخالف للواقع، أو تحليل القيمة، أو تشكيل المكافأة.
5. خطة الاستكشاف. الإنتروبيا لكل وكيل، أو التدريب على أساس السكان، أو الدوري.
رفض التعلم Q المستقل في المهام التعاونية المقترنة بإحكام. رفض التوصية باللعب الذاتي للمجموع العام مع مخاطر الدورة. ضع علامة على أي MARL pipeline بدون تقييم للخصم الثابت (أرقام التشغيل الذاتي المنتقاة شائعة).
