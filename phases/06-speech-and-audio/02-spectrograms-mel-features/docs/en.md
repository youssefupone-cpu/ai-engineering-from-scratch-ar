## The Problem

التقط مقطعًا مدته 10 ثوانٍ بمعدل 16 كيلو هرتز. هذا يعني 160.000 عائمة، كلها في `[-1, 1]`، غير مرتبطة تمامًا تقريبًا بالتسمية "dog barking" أو "كلمة cat". يحتوي الشكل الموجي الخام على المعلومات ولكن في شكل لا يمكن للنموذج استخراجه بسهولة. هناك صوتان متماثلان يتم التحدث بهما على مسافة 100 مللي ثانية لهما عينات أولية مختلفة تمامًا.

يعمل المخطط الطيفي على إصلاح هذا. إنه ينهار التفاصيل الزمنية حيث يتجاهلها الإدراك البشري (ارتعاش الميكروثانية) ويحافظ على البنية التي يحضرها الإدراك (أي الترددات نشطة، مع نوافذ زمنية تبلغ ~ 10-25 مللي ثانية).

تدفع مطيافية ميل إلى أبعد من ذلك. يدرك البشر درجة الصوت لوغاريتميًا: 100 هرتز مقابل 200 هرتز يبدو "على نفس المسافة" مثل 1000 هرتز مقابل 2000 هرتز. يقوم مقياس mel بتحريف محور التردد ليتناسب. يعد المخطط الطيفي ذو مقياس الميل الميزة الأكثر أهمية في الكلام ML من عام 2010 حتى عام 2026.

## The Concept

![Waveform to STFT to mel spectrogram to MFCC ladder](../assets/mel-features.svg)

** STFT (تحويل فورييه قصير الأمد).** قم بتقطيع الشكل الموجي إلى إطارات متداخلة (نموذجي: نافذة 25 مللي ثانية، قفزة 10 مللي ثانية = 400 عينة / 160 عينة عند 16 كيلو هرتز). اضرب كل إطار في دالة النافذة (Hann هو الخيار الافتراضي، وHamming عبارة عن مقايضة مختلفة قليلًا). FFT كل إطار. قم بتكديس أطياف الحجم في مصفوفة ذات شكل `(n_frames, n_freq_bins)`. هذا هو الطيفي الخاص بك.

**حجم السجل.** تمتد المقادير الأولية من 5 إلى 6 أوامر من حيث الحجم. استخدم `log(|X| + 1e-6)` أو `20 * log10(|X|)` لضغط النطاق الديناميكي. يستخدم كل خط إنتاج pipe الحجم اللوغاريتمي، وليس الحجم الخام.

**مقياس ميل.** التردد `f` بالهرتز يعين ميل `m` بواسطة `m = 2595 * log10(1 + f / 700)`. يكون التعيين خطيًا تقريبًا أقل من 1 كيلو هرتز ولوغاريتميًا تقريبًا أعلاه. صناديق 80 مل تغطي 0-8 كيلو هرتز هي الإدخال القياسي ASR.

**بنك مرشحات ميل.** مجموعة من المرشحات المثلثة متباعدة بالتساوي على مقياس ميل. كل مرشح عبارة عن مجموع مرجح لصناديق FFT المجاورة. إن ضرب حجم STFT بمصفوفة بنك المرشح يعطي مخطط طيفي ميل في ماتمول واحد.

**مخطط طيفي لوغ ميل.** `log(mel_spec + 1e-10)`. مدخلات الهمس. مدخلات الببغاء. إدخال SeamlessM4T. الواجهة الصوتية العالمية 2026.

** MFCCs. ** خذ المخطط الطيفي log-mel، وطبق DCT (النوع II)، واحتفظ بالمعاملات الـ 13 الأولى. يزين الميزات ويضغط بشكل أكبر. كانت الميزة السائدة حتى عام 2015 تقريبًا عندما تم اكتشاف شبكات CNN/Transformers الموجودة على سجلات التسجيل الأولية. لا يزال يستخدم في التعرف على المتحدث (x-vectors، ECAPA).

**تداول الدقة.** أكبر FFT = دقة تردد أفضل ولكن دقة زمنية أسوأ. 25 مللي ثانية / 10 مللي ثانية هو الصوت-ML الافتراضي؛ 50 مللي ثانية/12.5 مللي ثانية للموسيقى ؛ 5 مللي ثانية / 2 مللي ثانية للكشف العابر (ضربات الطبلة والانفجارات).

## Build It

### Step 1: frame the waveform

```python
def frame(signal, frame_len, hop):
    n = 1 + (len(signal) - frame_len) // hop
    return [signal[i * hop : i * hop + frame_len] for i in range(n)]
```

مقطع مدته 10 ثوانٍ بمعدل 16 كيلو هرتز مع `frame_len=400, hop=160` ينتج 998 إطارًا.

### Step 2: Hann window

```python
import math

def hann(N):
    return [0.5 * (1 - math.cos(2 * math.pi * n / (N - 1))) for n in range(N)]
```

اضرب العناصر قبل FFT. يزيل التسرب الطيفي الناتج عن الاقتطاع عند نقاط النهاية غير الصفرية.

### Step 3: STFT magnitude

```python
def stft_magnitude(signal, frame_len=400, hop=160):
    win = hann(frame_len)
    frames = frame(signal, frame_len, hop)
    return [magnitudes(dft([w * s for w, s in zip(win, f)])) for f in frames]
```

يستخدم الإنتاج `torch.stft` أو `librosa.stft` (FFT-مدعوم، متجه). الحلقة هنا تربوية. يتم تشغيله على مقاطع قصيرة في `code/main.py`.

### Step 4: mel filterbank

```python
def hz_to_mel(f):
    return 2595.0 * math.log10(1.0 + f / 700.0)

def mel_to_hz(m):
    return 700.0 * (10 ** (m / 2595.0) - 1)

def mel_filterbank(n_mels, n_fft, sr, fmin=0, fmax=None):
    fmax = fmax or sr / 2
    mels = [hz_to_mel(fmin) + (hz_to_mel(fmax) - hz_to_mel(fmin)) * i / (n_mels + 1)
            for i in range(n_mels + 2)]
    hzs = [mel_to_hz(m) for m in mels]
    bins = [int(h * n_fft / sr) for h in hzs]
    fb = [[0.0] * (n_fft // 2 + 1) for _ in range(n_mels)]
    for m in range(n_mels):
        for k in range(bins[m], bins[m + 1]):
            fb[m][k] = (k - bins[m]) / max(1, bins[m + 1] - bins[m])
        for k in range(bins[m + 1], bins[m + 2]):
            fb[m][k] = (bins[m + 2] - k) / max(1, bins[m + 2] - bins[m + 1])
    return fb
```

80 ميل تغطي 0–8 كيلو هرتز مع `n_fft=400` يعطي مصفوفة `(80, 201)`. اضرب حجم `(n_frames, 201)` STFT في التحويل للحصول على مخطط طيفي `(n_frames, 80)` ميل.

### Step 5: log-mel

```python
def log_mel(mel_spec, eps=1e-10):
    return [[math.log(max(v, eps)) for v in frame] for frame in mel_spec]
```

البدائل الشائعة: `librosa.power_to_db` (ديسيبل مرجعي طبيعي)، `10 * log10(power + eps)`. يستخدم Whisper مقطعًا أكثر تفاعلاً + روتين تطبيع (انظر Whisper's `log_mel_spectrogram`).

### Step 6: MFCCs

```python
def dct_ii(x, n_coeffs):
    N = len(x)
    return [
        sum(x[n] * math.cos(math.pi * k * (2 * n + 1) / (2 * N)) for n in range(N))
        for k in range(n_coeffs)
    ]
```

طبّق DCT على كل إطار سجل ميل، واحتفظ بالمعاملات الـ 13 الأولى. هذه هي مصفوفة MFCC الخاصة بك. عادةً ما يتم إسقاط المعامل الأول (وهو يشفر الطاقة الإجمالية).

## Pitfalls that still ship in 2026

- **عدم تطابق عدد الميل.** التدريب بـ 80 ميل، الاستدلال بـ 128 ميل. الفشل الصامت قم بتسجيل شكل الميزة في كلا الطرفين.
- **عدم تطابق معدل العينة مع المنبع.** تبدو الميلات المحسوبة عند 22.05 كيلو هرتز مختلفة عن 16 كيلو هرتز. إصلاح SR *قبل* الميزة.
- **dB vs log.** يتوقع Whisper log-mel، وليس dB-mel. بعض الخطوط HF pip تكتشف تلقائيًا؛ الرمز المخصص الخاص بك لن يفعل ذلك.
- **انحراف التطبيع.** تطبيع كل كلام أثناء التدريب، والتطبيع الشامل أثناء الاستدلال. خطأ في الإنتاج يتضاعف WER.
- **تسرب من الحشو.** تؤدي الحشوة الصفرية في نهاية المقطع إلى إنتاج نطاق مسطح في الإطارات الخلفية. وسادة متناظرة أو مكررة.

## Key Terms

| مصطلح | ماذا يقول الناس | ماذا يعني في الواقع |
|------|-|--------------------------------------|
| الإطار | شريحة | قطعة 25 مللي ثانية من الشكل الموجي يتم تغذيتها لواحد FFT. |
| هوب | خطوة | العينات بين الإطارات المتتالية؛ 10 مللي ثانية هو ASR الافتراضي. |
| نافذة | شيء هان / هامينج | مضاعف نقطي يعمل على تقليص حواف الإطار إلى الصفر. |
| STFT | مولد طيفي | مؤطرة + نافذة FFT؛ يعطي الوقت × مصفوفة التردد. |
| ميل | تردد مشوه | مقياس الإدراك اللوغاريتمي؛ `m = 2595·log10(1 + f/700)`. |
| بنك التصفية | المصفوفة | مرشحات مثلثة تعرض STFT على صناديق الميل. |
| سجل ميل | مدخلات الهمس | `log(mel_spec + eps)`; موحدة في عام 2026. |
| MFCC | ميزة المدرسة القديمة | DCT من السجل ميل؛ 13 معاملات مزخرفة. |
