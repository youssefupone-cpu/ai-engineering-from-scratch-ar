بالنظر إلى النموذج المستهدف (ASR / TTS / المصنف / مكبر الصوت / الموسيقى) وإدخال الصوت (معدل العينة، المجال)، الإخراج:

1. نوع الميزة. Log-mel أو mel أو MFCC أو شكل موجة خام أو برنامج ترميز منفصل (EnCodec أو SoundStream). سبب جملة واحدة.
2. عدد ميل ونطاق التردد. `n_mels`، `fmin`، `fmax`. السبب مرتبط بالمجال (الكلام مقابل الموسيقى) وهدف النموذج.
3. الإطار والقفز. `frame_len`، `hop_len`، نوع النافذة. السبب مرتبط بالحل الزمني المطلوب.
4. التطبيع. متوسط/فار لكل نطق، أو إحصائيات عالمية، أو ديسيبل مع مرجع ثابت؛ قبل أو بعد الميزات.
5. مقتطف التحقق من الصحة. Python التي تطبع الشكل الناتج، min/max، mean/std على مقطع مرجعي مدته ثانية واحدة وتؤكد أنها تتوافق مع التدريب.

رفض شحن ميزة pipeline التي يختلف عدد إطاراتها/قفزاتها/ميلها عن تكوين التدريب المنشور للنموذج المستهدف. قم بوضع علامة على أي إعداد يستند إلى MFCC لـ Whisper أو Parakeet كخطأ - فهذه النماذج تستهلك log-mel. قم بوضع علامة على أي مستخرج ميزات دون تأكيد التطبيع.
