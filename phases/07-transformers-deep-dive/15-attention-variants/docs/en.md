# متغيرات الانتباه - النافذة المنزلقة، المتناثرة، التفاضلية
> الاهتمام الكامل عبارة عن دائرة. كل رمز يرى كل رمز، والذاكرة تدفع الثمن. أربعة أنواع مختلفة تثني شكل الدائرة وتستعيد نصف التكلفة.
**النوع:** بناء
** اللغات: ** بايثون
**المتطلبات الأساسية:** المرحلة 7 · 02 (انتباه ذاتي)، المرحلة 7 · 03 (رؤوس متعددة)، المرحلة 7 · 12 (KV ذاكرة التخزين المؤقت / انتباه فلاش)
**الوقت:** ~60 دقيقة
## المشكلة
يتطلب الاهتمام الكامل `O(N²)` من الذاكرة و`O(N²)` حسابًا في طول التسلسل. بالنسبة إلى Llama 3 70B ذات سياق 128 كيلو بايت، فإن ذلك يمثل 16 مليار إدخال انتباه لكل طبقة، مضروبًا في 80 طبقة. يخفي Flash Attention (الدرس 12) ذاكرة التنشيط `O(N²)` ولكنه لا يغير التكلفة الحسابية - كل رمز مميز يظل مرتبطًا بكل رمز مميز آخر.
ثلاث فئات من المتغيرات تغير طوبولوجيا مصفوفة الانتباه نفسها:
1. ** تنبيه النافذة المنزلقة (SWA).** يهتم كل رمز بنافذة ثابتة للجيران، وليس البادئة الكاملة. تنخفض الذاكرة والحساب إلى `O(N · W)` حيث `W` هي النافذة. جيما 2/3، الطبقات الأولى لميسترال 7B، Phi-3-Long.
2. ** انتباه متناثر / حجب. ** يتم تسجيل النقاط للأزواج المحددة `(i, j)` فقط؛ يضطر الباقي إلى الصفر الوزن. Longformer، BigBird، OpenAI محول متناثر.
3. **الانتباه التفاضلي.** احسب خريطتين للانتباه مع إسقاطات Q/K منفصلة، ​​واطرح إحداهما من الأخرى. يقتل "مصرف الانتباه" الذي ينزف الوزن في الرموز القليلة الأولى. محول مايكروسوفت DIFF (2024).
هذه تتعايش. غالبًا ما يخلط نموذج الحدود لعام 2026 بينهما: فمعظم الطبقات هي SWA-1024، وكل خمس منها عبارة عن اهتمام عالمي كامل، وعدد قليل منها عبارة عن رؤوس تفاضلية تعمل على تنظيف عملية الاسترجاع. إن نسبة Gemma 3 5:1 SWA إلى العالمية هي النسبة الافتراضية الحالية في الكتاب المدرسي.
##المفهوم
### تنبيه النافذة المنزلقة (SWA)
كل استعلام في الموضع `i` يتعامل فقط مع المواضع في `[i - W, i]` (سببي SWA) أو `[i - W/2, i + W/2]` (ثنائي الاتجاه). الرموز الموجودة خارج النافذة تحصل على `-inf` في مصفوفة النتائج.
```
full causal:           sliding window (W=4):
positions 0-7          positions 0-7, W=4
    0 1 2 3 4 5 6 7        0 1 2 3 4 5 6 7
0 | x                0 |  x
1 | x x              1 |  x x
2 | x x x            2 |  x x x
3 | x x x x          3 |  x x x x
4 | x x x x x        4 |    x x x x
5 | x x x x x x      5 |      x x x x
6 | x x x x x x x    6 |        x x x x
7 | x x x x x x x x  7 |          x x x x
```

بالنسبة إلى `N = 8192` و`W = 1024`، تحتوي مصفوفة النتائج على 1024 × 8192 صفًا غير صفري في التوقع - وهو تخفيض بمقدار 8 ×.
**KV تتقلص ذاكرة التخزين المؤقت باستخدام SWA.** فقط آخر `W` من الرموز المميزة لـ K وV يجب الاحتفاظ بها لكل طبقة. بالنسبة لتكوين Gemma-3-ish (نافذة 1024، سياق 128 كيلو بايت)، تنخفض ذاكرة التخزين المؤقت KV بمقدار 128×.
**تكلفة الجودة.** SWA- المحولات فقط هي التي تواجه صعوبة في الاسترجاع بعيد المدى. الإصلاح: دمج طبقات SWA مع طبقات الاهتمام الكامل. تستخدم جيما 3 5:1 SWA:عالمي. استخدم ميسترال 7B مكدسًا سببيًا -SWA حيث "تتدفق المعلومات للأمام" من خلال النوافذ المتداخلة - تعمل كل طبقة على توسيع مجال الاستقبال الفعال بمقدار `W`، وبعد `L` من الطبقات، يمكن للنموذج حضور `L × W` الرموز المميزة مرة أخرى.
### انتباه متناثر / محظور
اختر نمطًا متناثرًا `N × N` مسبقًا. ثلاثة أشكال قانونية:
- **محلي + ممتد (OpenAI محول متفرق).** انتبه إلى آخر `W` من الرموز المميزة بالإضافة إلى كل `stride`-الرمز المميز قبل ذلك. يلتقط كلاً من المدى المحلي والبعيد عند حساب `O(N · sqrt(N))`.
- **Longformer / BigBird.** نافذة محلية + مجموعة صغيرة من الرموز العالمية (على سبيل المثال `[CLS]`) التي تحضر للجميع ويحضرها الجميع + روابط عشوائية متفرقة. سياق تجريبي 2× بجودة مطابقة.
- **الانتباه المتناثر الأصلي (DeepSeek, 2025).** تعرف على كتل `(Q, K)` المهمة؛ تخطي الكتل الصفرية على مستوى النواة. متوافق مع FlashAttention.
الاهتمام المتناثر هو قصة هندسة النواة. الرياضيات بسيطة (إخفاء مصفوفة النتيجة)؛ يأتي الفوز من عدم تحميل الإدخالات الصفرية في SRAM مطلقًا. FlashAttention-3 و2026 FlexAttention API make أنماط متفرقة مخصصة من الدرجة الأولى في PyTorch.
### الاهتمام التفاضلي (DIFF محول، 2024)
الاهتمام المنتظم به مشكلة "مصرف الانتباه": حيث يفرض softmax مجموع كل صف على 1، لذا فإن الرموز المميزة التي لا ترغب في الاهتمام بأي شيء معين تفريغ الوزن على الرمز المميز الأول (أو القلة الأولى). وهذا يسرق القدرة التي كان ينبغي أن تذهب إلى المحتوى الحقيقي.
يعمل الاهتمام التفاضلي على إصلاح ذلك عن طريق حساب خريطتي انتباه **اثنتين** وطرح:
```
A1 = softmax(Q1 K1^T / √d)
A2 = softmax(Q2 K2^T / √d)
DiffAttn = (A1 - λ · A2) V
```

حيث `λ` عبارة عن عددية مكتسبة (عادةً 0.5–0.8). A1 يلتقط أوزان المحتوى الحقيقية؛ A2 يلتقط الحوض. يؤدي الطرح إلى إلغاء الحوض، وإعادة تخصيص الوزن إلى الرموز ذات الصلة.
النتائج المعلنة (Microsoft 2024): انخفاض مستوى الحيرة بنسبة 5-10%، وسياق فعال أطول بمقدار 1.5-2× بنفس الطول المدرب، واسترجاع إبرة في كومة قش بشكل أكثر وضوحًا.

### الخطوة 1: القناع السببي الكامل (خط الأساس)
```python
def causal_mask(n):
    return [[0.0 if j <= i else float("-inf") for j in range(n)] for i in range(n)]
```

خط الأساس من الدرس 07. المثلث السفلي؛ الوزن صفر فوق القطر.
### الخطوة الثانية: قناع سببي للنافذة المنزلقة
```python
def swa_mask(n, window):
    M = [[float("-inf")] * n for _ in range(n)]
    for i in range(n):
        lo = max(0, i - window + 1)
        for j in range(lo, i + 1):
            M[i][j] = 0.0
    return M
```

معلمة واحدة — `window`. بالنسبة إلى `window >= n`، يمكنك استعادة الاهتمام السببي الكامل. بالنسبة إلى `window = 1`، يهتم كل رمز مميز بنفسه فقط.
### الخطوة 3: قناع متفرق محلي + مخطط
```python
def strided_mask(n, window, stride):
    M = [[float("-inf")] * n for _ in range(n)]
    for i in range(n):
        lo = max(0, i - window + 1)
        for j in range(lo, i + 1):
            M[i][j] = 0.0
        for j in range(0, i + 1, stride):
            M[i][j] = 0.0
    return M
```

نافذة محلية كثيفة بالإضافة إلى كل رمز مميز `stride` يعود إلى بداية التسلسل. ينمو الحقل الاستقبالي في خطوات السجل بطبقات إضافية.
### الخطوة 4: الاهتمام التفاضلي
```python
def diff_attention(Q1, K1, Q2, K2, V, lam):
    A1 = softmax_causal(Q1 @ K1.T / sqrt_d)
    A2 = softmax_causal(Q2 @ K2.T / sqrt_d)
    return (A1 - lam * A2) @ V
```

يمرر انتباهين، ويطرح بمعامل خلط مكتسب. في الكود، نقوم بمقارنة الخريطة الحرارية لمشتت الانتباه للتفاضل الفردي مقابل التفاضلي ونشاهد انهيار الحوض.
### الخطوة 5: KV أحجام ذاكرة التخزين المؤقت
اطبع حجم ذاكرة التخزين المؤقت لكل طبقة عند `N = 131072` لكل متغير. SWA وتنخفض المتغيرات المتفرقة بمقدار 10–100×. الزوجية التفاضلية. ادفع فاتورة ذاكرتك بوعي.

```python
from transformers import AutoModelForCausalLM

```

يقبل FlexAttention في PyTorch 2.5+ وظيفة القناع:
```python
from torch.nn.attention.flex_attention import flex_attention, create_block_mask

def swa_pattern(b, h, q_idx, kv_idx):
    return (q_idx - kv_idx < 1024) & (q_idx >= kv_idx)

mask = create_block_mask(swa_pattern, B=batch, H=heads, Q_LEN=n, KV_LEN=n)
out = flex_attention(q, k, v, block_mask=mask)
```

يتم تجميع هذا إلى نواة Triton مخصصة. في حدود 10% من سرعة FlashAttention-3 للأنماط الشائعة، ووظيفة القناع قابلة للاستدعاء في لغة Python.
** متى تختار كل منها: **
- **اهتمام كامل خالص** — كل طبقة تصل إلى سياق يصل إلى 16 كيلو بايت تقريبًا، أو عندما تكون جودة الاسترجاع ذات أهمية قصوى.
- **SWA + المزيج العام** — سياق طويل (> 32 كيلو بايت)، تدريب واستدلال مرتبط بالذاكرة. الافتراضي 2026 فوق 32 كيلو بايت.
- **انتباه الكتلة المتفرقة** — نواة مخصصة، ونمط مخصص. مخصصة لأحمال العمل المتخصصة (الاسترجاع والصوت).
- **الاهتمام التفاضلي** — أي عبء عمل يكون فيه التلوث الذي يصرف الانتباه مؤلمًا (سياق طويل RAG، إبرة في كومة قش).

## تمارين
1. **سهل.** قم بتشغيل `code/main.py`. تحقق من SWA في `window=4` صفر لكل شيء خارج آخر 4 رموز مميزة لكل صف. تحقق من أن `window=n` يعيد إنتاج الاهتمام السببي الكامل بشكل متطابق.
2. **متوسط.** قم بتنفيذ السببية SWA مع `window=1024` أعلى الدرس 07. تدريب لمسافة 1000 خطوة على شكسبير الصغير. ما مقدار تراجع خسارة فال مقابل الاهتمام الكامل؟ كم تنخفض ذروة الذاكرة؟
3. **صعب.** تنفيذ مزيج طبقات 5:1 بنمط Gemma-3 (5 SWA، 1 عالمي) في النموذج النهائي. قارن جودة الخسارة والذاكرة والتوليد مع خطوط الأساس النقية SWA والعالمية النقية عند المعلمات المتطابقة.
4. **صعب.** تنفيذ الاهتمام التفاضلي باستخدام `λ` المكتسب لكل رأس. تدريب على مهمة استرجاع اصطناعية (إبرة واحدة، 2000 وسيلة تشتيت). قياس دقة الاسترجاع مقابل خط الأساس أحادي الاهتمام عند المعلمات المتطابقة.
