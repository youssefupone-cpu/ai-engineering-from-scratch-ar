# Attention Variants — Sliding Window, Sparse, Differential

> الاهتمام الكامل عبارة عن دائرة. كل رمز يرى كل رمز، والذاكرة تدفع الثمن. أربعة أنواع مختلفة تثني شكل الدائرة وتستعيد نصف التكلفة.

**النوع:** بناء
** اللغات: ** بايثون
**المتطلبات الأساسية:** المرحلة 7 · 02 (الانتباه الذاتي)، المرحلة 7 · 03 (رؤوس متعددة)، المرحلة 7 · 12 (KV ذاكرة التخزين المؤقت / انتباه الفلاش)
**الوقت:** ~60 دقيقة

## The Problem

يتطلب الاهتمام الكامل `O(N²)` الذاكرة و`O(N²)` حساب طول التسلسل. بالنسبة إلى Llama 3 70B ذات سياق 128 كيلو بايت، فإن ذلك يمثل 16 مليار إدخال انتباه لكل طبقة، مضروبًا في 80 طبقة. يخفي Flash Attention (الدرس 12) ذاكرة التنشيط `O(N²)` ولكنه لا يغير التكلفة الحسابية - حيث يظل كل رمز مميزًا مرتبطًا بكل رمز مميز آخر.

ثلاث فئات من المتغيرات تغير طوبولوجيا مصفوفة الانتباه نفسها:

1. **انتباه النافذة المنزلقة (SWA).** يهتم كل رمز بنافذة ثابتة للجيران، وليس البادئة الكاملة. تنخفض الذاكرة والحساب إلى `O(N · W)` حيث `W` هي النافذة. جيما 2/3، الطبقات الأولى لميسترال 7B، Phi-3-Long.
2. ** انتباه متناثر / حجب. ** يتم تسجيل النقاط للأزواج المحددة `(i, j)` فقط؛ يضطر الباقي إلى الصفر الوزن. Longformer، BigBird، OpenAI محول متناثر.
3. **الانتباه التفاضلي.** احسب خريطتين للانتباه مع إسقاطات Q/K منفصلة، ​​واطرح إحداهما من الأخرى. يقتل "مصرف الانتباه" الذي ينزف الوزن في الرموز القليلة الأولى. مايكروسوفت DIFF محول (2024).

هذه تتعايش. غالبًا ما يخلط نموذج الحدود لعام 2026 بينهما: فمعظم الطبقات هي SWA-1024، وكل خمس يمثل اهتمامًا عالميًا كاملاً، وحفنة قليلة عبارة عن رؤوس تفاضلية تعمل على تنظيف الاسترجاع. نسبة Gemma 3 5:1 SWA إلى العالمية هي النسبة الافتراضية الحالية في الكتاب المدرسي.

## The Concept

### Sliding Window Attention (SWA)

كل استعلام في الموضع `i` يتعامل فقط مع المواضع في `[i - W, i]` (سببية SWA) أو `[i - W/2, i + W/2]` (ثنائية الاتجاه). الرموز الموجودة خارج النافذة تحصل على `-inf` في مصفوفة النتائج.

```
full causal:           sliding window (W=4):
positions 0-7          positions 0-7, W=4
    0 1 2 3 4 5 6 7        0 1 2 3 4 5 6 7
0 | x                0 |  x
1 | x x              1 |  x x
2 | x x x            2 |  x x x
3 | x x x x          3 |  x x x x
4 | x x x x x        4 |    x x x x
5 | x x x x x x      5 |      x x x x
6 | x x x x x x x    6 |        x x x x
7 | x x x x x x x x  7 |          x x x x
```

بالنسبة إلى `N = 8192` و`W = 1024`، تحتوي مصفوفة النتيجة على 1024 × 8192 صفًا غير صفري في التوقع - وهو تخفيض بمقدار 8×.

**KV تتقلص ذاكرة التخزين المؤقت بـ SWA.** فقط آخر `W` من الرموز المميزة لـ K وV يجب الاحتفاظ بها لكل طبقة. بالنسبة لتكوين Gemma-3-ish (نافذة 1024، سياق 128 كيلو بايت)، تنخفض ذاكرة التخزين المؤقت KV بمقدار 128×.

**تكلفة الجودة.** SWA- المحولات فقط هي التي تعاني من الاسترجاع بعيد المدى. الإصلاح: تداخل طبقات SWA مع طبقات الاهتمام الكامل. تستخدم جيما 3 5:1 SWA:عالمية. استخدم ميسترال 7B مكدسًا سببيًا SWA حيث "تتدفق المعلومات للأمام" من خلال النوافذ المتداخلة - تعمل كل طبقة على توسيع مجال الاستقبال الفعال بمقدار `W`، وبعد `L` طبقات يمكن للنموذج حضور `L × W` الرموز المميزة مرة أخرى.

### Sparse / Block Attention

اختر نمطًا متفرقًا `N × N` مسبقًا. ثلاثة أشكال قانونية:

- **محلي + ممتد (OpenAI محول متناثر).** انتبه إلى آخر `W` من الرموز المميزة بالإضافة إلى كل `stride`-الرمز المميز قبل ذلك. يلتقط كلاً من المدى المحلي والبعيد عند حساب `O(N · sqrt(N))`.
- **Longformer / BigBird.** نافذة محلية + مجموعة صغيرة من الرموز العالمية (على سبيل المثال `[CLS]`) التي تحضر للجميع ويحضرها الجميع + روابط عشوائية متفرقة. سياق تجريبي 2× بجودة مطابقة.
- **الانتباه المتناثر الأصلي (DeepSeek, 2025).** تعرف على كتل المادة `(Q, K)`؛ تخطي الكتل الصفرية على مستوى النواة. متوافق مع FlashAttention.

الاهتمام المتناثر هو قصة هندسة النواة. الرياضيات بسيطة (إخفاء مصفوفة النتيجة)؛ يأتي الفوز من عدم تحميل الإدخالات الصفرية في SRAM. FlashAttention-3 و2026 FlexAttention API make أنماط متفرقة مخصصة من الدرجة الأولى في PyTorch.

### Differential Attention (DIFF Transformer, 2024)

الاهتمام المنتظم به مشكلة "مصرف الانتباه": حيث يفرض softmax مجموع كل صف على 1، لذا فإن الرموز المميزة التي لا ترغب في الاهتمام بأي شيء معين تفريغ الوزن على الرمز المميز الأول (أو القلة الأولى). وهذا يسرق القدرة التي كان ينبغي أن تذهب إلى المحتوى الحقيقي.

يعمل الاهتمام التفاضلي على إصلاح ذلك عن طريق حساب خريطتي انتباه **اثنتين** وطرح:

```
A1 = softmax(Q1 K1^T / √d)
A2 = softmax(Q2 K2^T / √d)
DiffAttn = (A1 - λ · A2) V
```

حيث `λ` عبارة عن عددية مكتسبة (عادةً 0.5–0.8). A1 يلتقط أوزان المحتوى الحقيقي؛ A2 يصور الحوض. يؤدي الطرح إلى إلغاء الحوض، وإعادة تخصيص الوزن إلى الرموز ذات الصلة.

النتائج المعلنة (Microsoft 2024): انخفاض مستوى الحيرة بنسبة 5-10%، وسياق فعال أطول بمقدار 1.5-2× بنفس الطول المدرب، واسترجاع إبرة في كومة قش بشكل أكثر وضوحًا.

### Variant Comparison

| البديل | حساب | KV ذاكرة التخزين المؤقت | الجودة مقابل كامل | استخدام الإنتاج |
|---------|--------|---------|-----------------|----------------|
| الاهتمام الكامل | يا(ن²) | O(N) لكل طبقة | خط الأساس | الطبقة الافتراضية لكل نموذج |
| SWA (نافذة 1024) | O(N·W) | O(W) لكل طبقة | -0.1 شخص جيد مع الطبقات العالمية | جيما 2/3، فاي-3-لونغ |
| محلية + متناثرة | O(N·√N) | مختلط | شبيه SWA | OpenAI محول متناثر، Longformer |
| BigBird (محلي + عالمي + عشوائي) | O(N) تقريبًا | مختلط | التطابقات كاملة في سياق 2× | سياق طويل مبكر BERT |
| متفرق أصلي (DeepSeek-V3.2) | O(N · الكسر النشط) | يا(ن) | في حدود 0.05 شخص | ديب سيك-V3.2, 2025 |
| التفاضلية | O(2·N²) | يا(2ن) | -5 إلى -10% | DIFF المحولات موديلات مطلع 2026 |

## Build It

انظر `code/main.py`. نحن ننفذ مقارنة قناع سببي يُظهر الاهتمام الكامل، SWA، المحلي+المخطّط، والتفاضلي جنبًا إلى جنب في تسلسل لعبة.

### Step 1: full causal mask (baseline)

```python
def causal_mask(n):
    return [[0.0 if j <= i else float("-inf") for j in range(n)] for i in range(n)]
```

خط الأساس من الدرس 07. المثلث السفلي؛ الوزن صفر فوق القطر.

### Step 2: sliding window causal mask

```python
def swa_mask(n, window):
    M = [[float("-inf")] * n for _ in range(n)]
    for i in range(n):
        lo = max(0, i - window + 1)
        for j in range(lo, i + 1):
            M[i][j] = 0.0
    return M
```

معلمة واحدة — `window`. بالنسبة إلى `window >= n`، يمكنك استعادة الاهتمام السببي الكامل. بالنسبة إلى `window = 1`، يهتم كل رمز مميز بنفسه فقط.

### Step 3: local + strided sparse mask

```python
def strided_mask(n, window, stride):
    M = [[float("-inf")] * n for _ in range(n)]
    for i in range(n):
        lo = max(0, i - window + 1)
        for j in range(lo, i + 1):
            M[i][j] = 0.0
        for j in range(0, i + 1, stride):
            M[i][j] = 0.0
    return M
```

نافذة محلية كثيفة بالإضافة إلى كل رمز مميز `stride` يعود إلى بداية التسلسل. ينمو الحقل الاستقبالي في خطوات السجل بطبقات إضافية.

### Step 4: differential attention

```python
def diff_attention(Q1, K1, Q2, K2, V, lam):
    A1 = softmax_causal(Q1 @ K1.T / sqrt_d)
    A2 = softmax_causal(Q2 @ K2.T / sqrt_d)
    return (A1 - lam * A2) @ V
```

يمرر انتباهين، ويطرح بمعامل خلط مكتسب. في الكود، نقوم بمقارنة الخريطة الحرارية لمشتت الانتباه للتفاضل الفردي مقابل التفاضلي ونشاهد انهيار الحوض.

### Step 5: KV cache sizes

اطبع حجم ذاكرة التخزين المؤقت لكل طبقة عند `N = 131072` لكل متغير. SWA وتنخفض المتغيرات المتفرقة بمقدار 10-100×. الزوجية التفاضلية. ادفع فاتورة ذاكرتك بوعي.

## Use It

أنماط الإنتاج 2026:

```python
from transformers import AutoModelForCausalLM
# Gemma 3 mixes SWA (window=1024) and global layers at 5:1.
model = AutoModelForCausalLM.from_pretrained("google/gemma-3-27b-it")
# print(model.config.sliding_window, model.config.layer_types)
```

يقبل FlexAttention في PyTorch 2.5+ وظيفة القناع:

```python
from torch.nn.attention.flex_attention import flex_attention, create_block_mask

def swa_pattern(b, h, q_idx, kv_idx):
    return (q_idx - kv_idx < 1024) & (q_idx >= kv_idx)

mask = create_block_mask(swa_pattern, B=batch, H=heads, Q_LEN=n, KV_LEN=n)
out = flex_attention(q, k, v, block_mask=mask)
```

يتم تجميع هذا إلى نواة Triton مخصصة. في حدود 10% من سرعة FlashAttention-3 للأنماط الشائعة، ووظيفة القناع قابلة للاستدعاء في لغة Python.

** متى تختار كل منها: **

- **اهتمام كامل خالص** — كل طبقة تصل إلى سياق يصل إلى 16 كيلو بايت تقريبًا، أو عندما تكون جودة الاسترجاع ذات أهمية قصوى.
- **SWA + مزيج عالمي** — سياق طويل (> 32 كيلو بايت)، تدريب واستدلال مرتبط بالذاكرة. الافتراضي 2026 فوق 32 كيلو بايت.
- **انتباه الكتلة المتفرقة** — نواة مخصصة، ونمط مخصص. مخصصة لأحمال العمل المتخصصة (الاسترجاع والصوت).
- **الاهتمام التفاضلي** — أي عبء عمل يكون فيه تلوث مصدر الانتباه مؤلمًا (سياق طويل RAG، إبرة في كومة قش).

## Key Terms

| مصطلح | ماذا يقول الناس | ماذا يعني في الواقع |
|------|-|--------------------------------------|
| انتبه النافذة المنزلقة (SWA) | "الاهتمام المحلي" | يعتني كل استعلام بآخر `W` من الرموز المميزة له؛ KV تتقلص ذاكرة التخزين المؤقت إلى `O(W)`. |
| مجال تقبلي فعال | "إلى أي مدى يرى النموذج" | في مكدس `L` من الطبقة SWA مع النافذة `W`، ما يصل إلى `L × W` من الرموز المميزة. |
| لونج فورمر / بيج بيرد | "محلي + عالمي + عشوائي" | أنماط متفرقة مع عدد قليل من الرموز العالمية التي تحضر دائمًا؛ النهج المبكر للسياق الطويل. |
| الاهتمام المتناثر الأصلي | "خدعة نواة DeepSeek" | تعلم التشتت على مستوى الكتلة؛ تخطي الكتل الصفرية على مستوى النواة مع الحفاظ على الجودة. |
| الاهتمام التفاضلي | "خريطتان، واحدة تطرح" | DIFF المحول: اطرح `λ` مرات خريطة الانتباه الثانية من الأولى لإلغاء مغاسل الانتباه. |
| بالوعة الاهتمام | "الوزن ينزف إلى الرمز المميز 0" | تطبيع Softmax يفرض مجموع الصفوف على 1؛ استعلامات غير معلوماتية تفريغ الوزن على الموضع 0. |
| فليكس الاهتمام | "قناع كالبيثون" | PyTorch 2.5+ API الذي يجمع وظائف القناع التعسفي في حبات على شكل FlashAttention. |
| مزيج نوع الطبقة | "5:1 SWA-إلى العالمية" | قم بتداخل طبقات الاهتمام المتناثرة والكاملة في مكدس للحفاظ على الجودة في الذاكرة المنخفضة. |
