المدخلات المحددة (مطالبة نصية / صورة واحدة / عدد قليل من الصور / التقاط الصور / الفيديو)، والإخراج المستهدف (شبكة / تدفق غاوسي / NeRF / سحابة نقطة)، وحالة الاستخدام (العرض في الوقت الفعلي، محرك اللعبة، AR / VR، سينمائي)، الإخراج:

1. خط الأنابيب. (أ) نشر متعدد العرض + ملاءمة ثلاثية الأبعاد (SV3D، CAT3D + 3DGS)، (ب) لقطة فردية مباشرة (LRM، TripoSR، InstantMesh)، (ج) تحويل النص إلى شبكة مع PBR (Meshy 4، Rodin Gen-1.5، Hunyuan3D 2.0)، (د) التقاط الصور + 3DGS (Gsplat، Postshot، Scaniverse).
2. النموذج الأساسي + الاستضافة. النموذج المسمى + مفتوح / مستضاف. قم بتضمين صلة الترخيص بالاستخدام التجاري.
3. ميزانية التكرار. الوقت المتوقع للإخراج الأول، وتكلفة التكرار، واستراتيجية التحسين.
4. الطوبولوجيا + المواد. تمريرة Remesh اللازمة؟ PBR متطلبات القناة (البياض، الخشونة، المعدني، العادي)؟ UV التخطيط آلي أم يدوي؟
5. التقييم. SSIM على المشاهدات المعلقة، CLIP النتيجة، مقاومة الماء للشبكة، عدد البولي، دقة الملمس.
6. هدف المنصة. الوحدة / غير الواقعية / الخلاط / الويب (three.js / Babylon) / AR (USDZ / glb).

ارفض شحن 3DGS مباشرة إلى محرك اللعبة بدون تمرير تحويل شبكي (معظم المحركات لا تعرض البقع محليًا). ارفض تحويل النص إلى ثلاثي الأبعاد للأحرف المفصلية المعقدة - استخدم سطرًا pipe مدركًا للتلاعب بدلاً من ذلك. قم بوضع علامة على أي مخرجات NeRF فقط عندما لا تتمكن أداة المصب من عرض NeRFs (معظم أدوات DCC).
