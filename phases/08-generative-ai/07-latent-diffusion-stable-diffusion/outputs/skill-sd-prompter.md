نظرًا للأسلوب السريع والهدف وشريط الجودة (معاينة سريعة / جودة المحفظة / جاهزة للطباعة)، الإخراج:

1. النموذج + نقطة التفتيش. SD 1.5 (أدوات قديمة)، SDXL-base + Refiner، SDXL-Turbo (سريع)، SD3.5-Large، Flux.1-dev (أفضل فتح)، Flux.1-schnell (فتح سريع)، أو مستضاف API (DALL-E 3، Imagen 4، Midjourney الإصدار 7). سبب جملة واحدة.
2. أخذ العينات. Euler A (إبداعي)، DPM-Solver++ 2M Karras (مستقر)، LCM (سريع)، أو جهاز أخذ العينات المطابق للتدفق (SD3/Flux). تضمين عدد الخطوات.
3. CFG مقياس. 0 للتربو / LCM، 3-4 للتدفق، 5-7 لـ SDXL، 7-10 لـ SD1.5. توثيق المقايضة.
4. الإضافات. ControlNet (الوضعية، العمق، الحاذق، المقطع)، IP-Adapter (الصورة المرجعية)، LoRA (النمط أو الموضوع)، T5 تبديل لـ SD3+.
5. موجه سلبي. السلسلة الفارغة الصريحة مقابل المحتوى المملوء (المصنوعات، الجودة المنخفضة، التشريح الخاطئ) مهم؛ تحديد كليهما.

رفض CFG > 10 لـ SDXL+ (المخرجات المشبعة). رفض > 50 خطوة لأخذ العينات على نقاط التفتيش غير القديمة (ثبات الجودة بمقدار 30). ارفض خلط LoRAs المدربة على نماذج أساسية مختلفة (SD 1.5 LoRA على SDXL مكسور بصمت). قم بالإبلاغ عن أي طلب للبشر الواقعيين دون تذكير بسياسة NSFW والتزييف العميق وسياسة حقوق الطبع والنشر.
