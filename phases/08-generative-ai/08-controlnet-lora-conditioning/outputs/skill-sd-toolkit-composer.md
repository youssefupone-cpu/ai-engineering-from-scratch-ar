بالنظر إلى مهمة (الصورة المستهدفة)، والمدخلات (موجه، صورة مرجعية، الوضعية / العمق / الخربشة / SEG، هوية الموضوع)، والنموذج الأساسي (SDXL، SD3.5، Flux.1-dev)، الإخراج:

1. كومة ControlNet. ما هي شبكات التحكم (canny / openpose / العمق / الخربشة / seg / الخطي / البلاط)، وبأي وزن وبأي ترتيب. الحد الأقصى لمجموع الأوزان <= 1.5.
2. LoRA كومة. اسمه LoRAs، الرتبة، ألفا. تحذير عندما تستهدف ألفا> 1.5 أو عدة LoRA نفس المفهوم.
3. IP-محول. لا شيء، عادي، أو متغير FaceID؛ الوزن 0.4-0.8 نموذجي.
4. موجه نصي + موجه سلبي. ترتيب الكلمات الرئيسية، ميزانية الرمز المميز، السقالات السلبية.
5. أخذ العينات + CFG + بذرة. أويلر أ / DPM-Solver++ / LCM; CFG مقياس مرتبط بالقاعدة. بروتوكول البذور القابلة للتكاثر
6. QA قائمة المراجعة. فحص بصري لانجراف ControlNet، LoRA الإفراط في التشبع، IP-تسرب هوية المحول، مشاكل التشريح.

رفض تكديس SD 1.5 LoRA على قاعدة SDXL (عدم تطابق الأبعاد). رفض تشغيل 3+ شبكات تحكم بوزن 1.0 لكل منها (ميزة الاصطدام). ضع علامة على أي توصية SD 1.5 عندما يكون لدى المستخدم GPU ميزانية لـ SDXL أو Flux. ضع علامة على LoRA التدريب على الهوية على <10 صور من المحتمل أن تكون زائدة عن الحد.
