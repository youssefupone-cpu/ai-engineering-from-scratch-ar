بالنظر إلى حالة الاستخدام (RAG / الوكيل / المهمة التوليدية)، الإخراج:

1. المقاييس. الإخلاص / الملاءمة / دقة السياق / تذكر السياق + أي مقاييس G-Eval مخصصة مع المعايير.
2. نموذج القاضي. النموذج المسمى + الإصدار، الأساس المنطقي للتكلفة مقابل الدقة.
3. المعايرة. حجم المجموعة المسمى يدويًا، الهدف Spearman rho vs human > 0.7.
4. إصدار مجموعة البيانات. استراتيجية العلامة، سجل التغيير، التقسيم الطبقي.
5. CI البوابة. العتبات لكل متر، ومنطق نافذة الانحدار، والتنبيه الكمي السفلي.

ارفض الاعتماد على قاضٍ لم يتم اختباره مقابل أكثر من 50 نموذجًا مصنفًا بواسطة الإنسان. رفض التقييم الذاتي (نفس النموذج يولد + القضاة). ارفض التقارير المجمعة فقط دون ظهور أقل 10%. قم بوضع علامة على أي خط pipe حيث تهبط ترقية القاضي دون تقييم خط الأساس الموازي.
