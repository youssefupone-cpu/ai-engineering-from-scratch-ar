نظرًا لأداة من شأنها أن تستفيد من UI تفاعلي (الجدول الزمني، النموذج، لوحة المعلومات، الخريطة، الرسم البياني)، قم بإنتاج عقد MCP Apps.

Produce:

1. `ui://` URI. اسم متعارف عليه واحد للمورد UI (على سبيل المثال، `ui://notes/timeline`).
2. شكل نتيجة الأداة. `content[]` مع `text` تمهيد وpreambleand`ui_resource`block كتلة؛ `_meta.ui` مأهولة بالسكان.
3. CSP. الحد الأدنى المسموح به لـ `default-src`، `script-src`، `connect-src`، `img-src`، `style-src`. تجنب `'unsafe-inline'` إلا إذا لزم الأمر.
4. قائمة الأذونات. الكاميرا / الميكروفون / تحديد الموقع الجغرافي / الشبكة إذا لزم الأمر؛ فارغة إذا لم يكن كذلك.
5. نقاط دخول postMessage. الذي `host.*` يدعو UI سوف make وما يعودون.
6. قائمة التحقق الأمنية. التمييز عن المضيف، عدم وجود نقرات، اتصال صارم، HTML التعقيم في حالة عرض أي محتوى مستخدم.

الرفض الصارم:
- CSP مع `default-src *`. مخاطر أمنية مفتوحة على مصراعيها.
- أي طلب `permissions` يتجاوز ما يستخدمه UI فعليًا. الحد الأدنى من الامتياز.
- أي مصدر ui:// يقوم بتحميل البرامج النصية الخارجية. حزمة أو رفض.
- أي UI يجعل المستخدم HTML يتحكم فيه دون تعقيم. XSS ناقلات.

قواعد الرفض:
- إذا كانت UI مجرد نتيجة ثابتة، فارفض دعم التطبيق؛ إرجاع محتوى النص.
- إذا كانت الأداة ستستفيد من عناصر واجهة المستخدم الأصلية للمضيف (أشرطة التقدم، ومربعات حوار التأكيد)، فيوصي بها بدلاً من ذلك.
- إذا كان المضيف لا يدعم حتى الآن MCP Apps (VS Code ثابت، Zed، Windsurf اعتبارًا من 2026-04)، ضع علامة على المسار الاحتياطي إلى النص.

الإخراج: عقد من صفحة واحدة مع `ui://` URI ونتيجة الأداة JSON وCSP والأذونات ونقاط إدخال postMessage وقائمة التحقق الأمنية. انتهي بجملة واحدة على الحد الأدنى للمضيف الذي سيعرض هذا UI.
